# Octicons（GitHub の印）

情報の窓のバージョンの行の、リポジトリを開くボタンの印（UI-303）。

| ファイル | 中身 |
|---|---|
| `mark-github-16.svg` | `@primer/octicons` 19.41.0 の `build/svg/mark-github-16.svg`。手を加えていない |
| `LICENSE` | 同じ版の `LICENSE`（MIT、Copyright (c) 2026 GitHub Inc.） |

ライセンスの文は配布物の `licenses/octicons-LICENSE.txt` に入り（`scripts/release.py`）、情報の窓の「使っているソフトウェア」から開ける。
印は GitHub の商標。リポジトリへのリンクの印としてだけ使い、形・色を変えない（画面の文字の色の 1 色で描く）。

# トラックブラウザー — 承認済み（2026-11-08）

共通索引はプリセットの保存範囲でインストゥルメント・マルチ・FX・FX チェーン・トラックを分類する。
画面は検索欄、インストゥルメント／FX／トラックの横ボタン、機器と Factory／User／フォルダーの木の順。
機器行とそのプリセット行は既存の機器一覧と同じアイコンを使う（Sampler は鍵盤、Drum Kit はドラム、FX はエフェクト）。
マルチは layers、FX チェーンは cable、トラックのプリセットと横ボタンは audio の既存アイコン。
左レールの入口だけは arrange（並んだトラック）とし、横ボタンのトラックと区別する。お気に入り・ドラッグ中も同じ種類のアイコンを保つ。
メーカーは機器行の補助表示と検索対象。検索は空白区切りの AND で親を残し、検索中は枝を開く。
お気に入りは索引 ID への参照。Factory は読むだけで、User へコピーして編集する。
右クリックは共通の分類に従う。読み込み・User へのコピーは「機器」（トラックプリセットは「トラック」）、お気に入りは「表示」。空所の再スキャンと標準プリセット復元は「機器」、展開・非表示の切り替えは「表示」。機器行の既存操作も維持する。
保存窓の「FX を含める」は新規時オフ、既存のコピーでは元の範囲を保持する。
FX 付きは +FX と表示し、音源と全インサートを置換する。FX 無しは既存 FX を残す。
センド・音量・パン・色まで保存する用途のためトラックの種類も残す。試聴は設けない。

| 項目 | トラック頭・音源スロット | FX の間・末尾 | FX の機器上 | アレンジの空き |
|---|---|---|---|---|
| 音源単体 | 音源を置換、既存 FX は保持 | 適用不可 | 適用不可 | 音源付きトラックを追加 |
| 音源 +FX | 音源と全インサートを置換 | 適用不可 | 適用不可 | 音源と FX のトラックを追加 |
| マルチ | 音源の木を置換。保存範囲に後段 FX がある場合はそれも置換 | 適用不可 | 適用不可 | マルチのトラックを追加 |
| FX／FX チェーン | トラック頭は FX を追加。音源スロットは適用不可 | 指定位置に追加 | 対象 FX を置換 | FX チャンネルを追加 |
| トラック | トラック頭は設定を適用。音源スロットは適用不可 | 適用不可 | 適用不可 | トラックを追加 |

成功した適用は、新規トラックを含め取り消し 1 回で戻る。音源 +FX は落とす前に
「インストゥルメントと FX を置き換え」と予告する。レイヤー内の音源を保存するときは
そのレイヤーの FX と範囲内マクロまでを保存し、他レイヤーや全体の後段 FX は含めない。
保存窓で同名があればボタンを「上書き保存」に変え、次の押下でだけ上書きする。

`browser.preset.list --tab instruments|effects|tracks --query <語>` は共通索引と木を返す。
`browser.preset.favourite --entry <id>` は参照を切り替える。
`browser.preset.save --track <id> --kind <範囲> --of <機器> --name <名前> --include_fx --folder <フォルダー>`
は User に保存する。同名は `--overwrite` を明示する。
`browser.preset.copy --entry <id> --name <名前> --folder <フォルダー>` は範囲を保持して User に写す。
`browser.preset.apply --entry <id> --target track|instrument|insert|effect|new` は落とし先の意味を指定する。
既存トラックへの適用には `--track`、FX の位置には `--at`、置換対象には `--of` を指定する。
これらは登録済みコマンドから CLI と MCP に共通に公開し、画面のディスク操作は曲の所有者へ渡す。

保存形式は DevicePreset / ChainPreset / TrackPreset を維持し、索引で統合する。
読み込みに伴う元ファイルの自動変換・上書きは行わない。プラグイン不足でも状態・配線・マクロ参照を保持する。
旧形式で内蔵機器の表示名が ID として保存されていた場合は、索引上で正規の ID に揃える。
旧保存先の種類・機器 ID のディレクトリは表示用フォルダーに含めない。
一覧の自動読み取りも曲の所有者ワーカーへ渡すが、保存窓・パレット・エラー表示・履歴は変更しない。
曲の読み込み・保存・音の準備・マクロの実行中は、自動読み取りを後に回す。

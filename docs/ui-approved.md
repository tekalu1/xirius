# 承認された画面の形

実装は、ここに書いた画面の形と、`docs/plan.toml` の UI・EDT・MIX・AUT・ARR の項目に合わせる。本文と plan が食い違うときは plan を正とし、食い違いを報告する。

## 用語（承認済み、2026-10-21）

画面・コマンドの名前・説明・CLI と MCP の文は、次の語で書く。乗り換え元の Studio Pro の言い方に揃える。

| 前の語 | 製品で使う語 | 残す場面 |
|---|---|---|
| 音源（楽器のプラグイン） | インストゥルメント | 音の出どころの意味のふつうの言葉（「音色・音源のライブラリー」など） |
| 曲のファイル（左のレールのタブ） | プール | — |
| 移調 | トランスポーズ | — |
| 音程・音高（音の高さ） | ピッチ | — |
| 音量（フェーダー・パラメーターの名前） | ボリューム | クリップのゲインは「ゲイン」 |
| コンプ（テイクの行を組み合わせる操作） | コンピング | コンプレッサーの略の「コンプ」 |
| 区間（アレンジの区切り・書き出しの範囲） | セクション | テイクの行をなぞった範囲の「区間」 |
| 読み込む（ファイルを曲に入れる操作） | インポート | プリセット・キーの割り当て・ほかのアプリの変更の「読み込む」、エラーの「読み込めません」 |

- ツールの名前（選択・鉛筆・試聴）は変えない。コマンドパレットでは、Studio Pro の名前「矢印」「ペイント」「リッスン」でも探せる。
- 「ミキサー」「曲」は変えない。

## 矢印の既定・レールの説明・再生位置の線（承認済み、2026-10-21）

- ピアノロールの矢印の既定は基本にする。設定 `edit.arrow.mode` に値が無いときは基本で、拡張を選んだ人は拡張のまま（UI-292）。
- 拡張のとき、ノートの上の端（ベロシティ）・下の端（分割）に指が乗っている間は、カーソルを上下の矢印（ベロシティ）・はさみ（分割）にし、その端に `ring` の色の 4 px の帯（丸い端、左右の端の当たりの内側）を重ねる。押している間とノートの中ほどでは帯を出さない（UI-292）。
- 左のレールのボタンの説明は、ボタンごとの名前（インストゥルメント・エフェクト・ファイル・プール）と、そのタブを開くキーにする（インストゥルメント F6・エフェクト F7・ファイル F9。プールはキーが無いので名前だけ）。「ブラウザーを表示 F5」は出さない（UI-293）。
- 再生位置の縦の線のまわりのぼかしの影（光）を無くす。線と上の三角は残す（UI-294）。

## インストゥルメントのメニュー（承認済み、2026-10-21、UI-297）

- 幅は 260 px のまま。長い名前（「{名前} — {作り手}」）は行の幅で切って末尾に「…」を付け、指を載せると全文を吹き出しに出す。切れない名前には吹き出しを出さない。
- 一番上に検索の欄を置く。エフェクトのメニューと同じ部品（虫めがねと、空のときの薄い「検索」）。開いたらすぐ打て、名前と作り手で絞る。↑↓ で選び、Enter で決める。選べない行（スキャン中の知らせなど）では Enter は何もしない。
- 見える 12 行より多いときは、行の右端（右から 1 px）に幅 4 px・角の丸み 2 px の `thumb` の色のつまみを出す。高さは 行の高さ×12×12/件数（16 px より小さくしない）、位置は送った量に比例する。エフェクトのメニューにも同じつまみを出す。

## ほかのアプリの変更（承認済み、2026-10-18、UI-289、案 B）

- 画面は開いている曲のフォルダーの `project.json` を見張る。OS の知らせ（Windows では ReadDirectoryChangesW）を受け、受けられない所では 2 秒ごとに更新時刻を見る。続けて書かれたら、最後の書き込みから 300 ms 待って 1 回だけ扱う。画面自身の保存は、中身が画面の書いたものと同じかで見分け、何も出さない。
- 札は UI-288 の警告の札と同じ場所（レーンの左下）・同じ作りで、頭に情報の印（ⓘ）を置く。
- 保存していない変更が無いとき: すぐ読み込み、「ほかのアプリの変更を読み込みました」と「元に戻す」を 4 秒出す。× は置かない。「元に戻す」は Ctrl+Z と同じ。
- 保存していない変更があるとき: 「ほかのアプリで曲が変更されました」と「読み込む」・× を、押すまで出す。× の後は画面の曲のまま。ほかのアプリがもう一度変えたら、また聞く。画面で保存して曲が書き戻されたら、札を下げる。
- 読み込みは履歴の 1 段「ほかのアプリの変更」として、元に戻す・やり直しと同じ道で入れる。曲を開き直さないので、再生は止めず、プラグインを準備中（ENG-064）のカードも出さない。
- ドラッグ・録音・名前の入力・保存の幕・警告の札の間は読み込まず、札も出さない。終わってから扱う。
- AI の保存の許可が無いときは `project.json` が変わらないので、何も起きない。

## 保存中の表示（承認済み、2026-10-18、UI-288）

- Ctrl+S と曲のメニューの「保存」は、押した時から上の帯の印を回る矢印と「保存中」にする。450 ms 以上保ち、書き終えたら「保存済み」に戻す。成功の札は出さない。200 ms を超える書き込みでは UI-061 の幕と「保存しています」のカードを出す。
- 別名で保存・はじめての保存は、場所を選ぶ窓を閉じてから上の細い線を出す。200 ms を超えたら幕と「別名で保存しています」のカードを出す。カードはコピー済みバイト数の割合を棒で示し、数字は出さず、塗りは待ちの線と同じにする。「中止 Esc」と Esc で中止する。中止・失敗時は途中のフォルダーを消して元の曲を保ち、成功時だけ名前と保存先を切り替えて「保存済み」にする。
- 閉じる・別の曲を開くときの保存待ちも、200 ms を超えたら「保存しています」の幕を出す。保存の幕の間はスペースによる再生・停止だけ受け、編集を止める。
- 保存・自動保存・履歴の書き込みに失敗したら、上の印を警告の色の「⚠ 保存できません」にする。レーンの左下に消えない警告の札を 1 つだけ出し、理由 1 つと「別名で保存…」「もう一度」、閉じる × を置く。× で札を閉じても、保存が成功するまで印を残す。
- 理由は「ディスクの空きが足りないため保存できません」「このフォルダーには書き込めないため保存できません」「保存先のフォルダーが見つからないため保存できません」、その他は「保存できません（OS の文）」。パスは出さず、保存失敗では下のエラー行を使わない。

## メイン画面（承認済み、2026-10-12）

- 画面の要点
  - 上のバーと窓のタイトルバーを 1 つにする（Mac は左に信号機、Windows は右に 3 つのボタン）。
  - 線・箱を減らし、面の明るさの差と余白でまとめる。枠線・上辺の光・グラデーション（値を表す物を除く）を使わない。
  - 文字の後ろに薄い色の面を敷かない。薄い文字を使わない。角丸の物の 1 辺だけに色を付けない。
  - アレンジのセクションは物ごと塗る。クリップは中立の面に、中身（ノート・波形）だけをトラックの色で描く。
  - フォルダーは角丸の入れ物で、中の行に角を出さない。外のトラックのまとまりも角丸の塊にする。範囲は深さごとの縦の線で示す（「線を引かない」の例外）。
  - 右のパネル（インスペクター）は置かない。色はトラックのアイコン、出力は広げたトラックの頭、インサート・センドはミキサー。（2026-10-22 に UI-312 で改めた。右のパネルは置かないまま、インスペクターは左のレールのプールの下の「i」から、ブラウザーと同じ場所・幅の面として開く。F4 でも開閉する。下の「インスペクターとトラックのトランスポーズ」）
  - 曲名のメニューから保存・別名で保存・バージョンの一覧。保存の印からバージョンの一覧。
  - 画面の中の文言は、製品に置くものだけ。一般的な製品のふつうの言い方にする。
  - モックの語のうち「版」「録音待ち」「強さ」は、実装では「バージョン」「録音準備」「ベロシティ」と書く（2026-10-12、文言の直し。2026-10-21 に「録音待機」から「録音準備」に直した。Studio Pro のボタンの名前に合わせる）。

- 書体は英数字が Inter、日本語が Noto Sans JP。時間・BPM・dB・ms は桁幅をそろえる。色・余白・角丸の値は `docs/design-rules.md` と `xirius-design` を使う。
- 左にブラウザー、中央にトラックの頭と時間軸、下にピアノロール / ミキサーのドロワー。選択中のタブをもう一度押すと畳み、境目のドラッグで高さを変える。境目はホバーで示す。
- トラックの追加は列の頭の＋に集める。M・S・録音準備・モニターは小さいボタンで、入の色は黄・緑・赤・青。インストゥルメントの窓は鍵盤のアイコンから開く。
- フォルダーは入れ子にでき、字下げは深くなりすぎないよう上限を設け、深さを印でも示す。トラックを複数選んで並べ替え・出し入れでき、Alt なら複製。行間の印とフォルダーの明るさで落とし先を示す。
- アレンジのセクションとテンポの帯はルーラーの下に固定し、トラック列を送っても残す。表示はトラック列の頭から切り替える。ループの帯の空きで左右どちらへドラッグしても範囲を作れ、端は長さ、本体は位置を変える。Shift でスナップを外す。
- グリッドは上のバーの磁石のスイッチと値のボタンに分ける（UI-302）。スイッチはスナップの入り切りだけで、値のボタン（1/16 と ▾）を押すとモード・音価・3 連・自動クオンタイズを開く。Ctrl+ホイールは縦、Ctrl+Shift+ホイールは横の縮尺を、ポインターの位置を中心に変える。
- オートメーションは持ち主のトラックと同じ面に複数並べ、＋で追加、×で閉じる。追加直後も現在値の線を描く。モードは形の異なるアイコン。コントローラーのレーンは個別にも全体でも畳める。
- 履歴は 1 つのボタンにまとめ、人と AI の操作を同じ列にする。取り消し・やり直しは頭に置く。AI の編集中は範囲の走査・対象の明滅と移動・星・履歴の光を穏やかに示し、終わると人が触るまで縁だけを残す。動きを減らす環境では縁だけにする。
- 曲名のメニューは新規・開く・最近の曲、保存・別名で保存・バージョンの一覧、書き出し・曲の設定の順。バージョンは時間順の列にし、自動保存は小さい点、名前付きは大きい点。選ぶとトラック数・長さ・変わったトラックを示し、「このバージョンに戻す」「別の曲として開く」と、列の頭の「今の状態に名前を付ける」を置く。
- ブラウザーのインストゥルメント・エフェクトは種類・ベンダー・形式・名前・お気に入りで切り替え、内蔵と外部を分けない。ファイルは場所のタブと＋、パンくず、フォルダーからファイルの順。行は種類・名前・長さ、選択時に試聴の帯。常設の操作説明は置かず、必要な案内はツールチップにする。

## 書き出しパネル（承認済み、2026-10-12）

- 上のバーの書き出しボタン（箱から上向きの矢印）か Ctrl+E で開く。曲が書き出し後に変わるとボタンに点を付ける。
- ボタンの直下に右端をそろえて浮く面を開く。幅は 576 px を基準に、窓の内側に収める。高さも窓内に収め、中身をスクロールする。
- パネルの頭に「ミックスダウン / ステム」の切り替え。その下に範囲（曲全体 / ループ範囲 / セクション）、形式、サンプルレート、ビット深度、置き場所とファイル名を並べ、下に「書き出す」。既定は曲の設定を使う。
- 範囲の切り替えの下に曲のセクションの帯を置く。選んだ範囲を窓で示し、外を暗くする。ループ範囲は線でも示す。セクションは複数選べ、最初のセクションの頭から最後のセクションの終わりまでを書き出す。
- WAV / FLAC、44.1 / 48 / 96 kHz、16 / 24 / 32f bit を切り替える。形式で使えない値は選べない。MP3 の条件は後の節に従う。
- ステムではトラックとバスのチェック一覧と「トラックごと / バスごと / 選んだもの」を出す。既定の置き場所は曲の `Mixdown/`・`Stems/`、名前の型は `{曲}_{トラック}`。
- 置き場所は曲のフォルダーと保存先の札で示す。名前の型は `{曲}`・`{トラック}` を札で示し、拡張子は入力欄の外に分ける。
- 書き出し中は行ごとに進み具合を出し、止められる。完了したミックスダウンには LUFS とトゥルーピーク、行の操作に「フォルダーを開く」を出す。
- 書き出したファイルを一覧に残し、名前・形式・サンプルレート・深度（MP3 はビットレート）・長さを示す。曲と同じか古いかを印で示し、変わったトラックは色の点で示す。古いステムは「更新」で変わった分だけ作り直す。
- 一覧は書き出しごとのカード。上段に名前・形式などの情報・状態と操作を置く。ステムは山形を押すとファイルごとの行を展開し、各行にも値と状態を出す。完了直後の「フォルダーを開く」は文字付き、その後の操作ではアイコンだけにする。

## 設定の画面（承認済み、2026-10-12）

- アプリの上に重ねるモーダル。左に項目（一般・オーディオ・MIDI・プラグイン・編集・ショートカット）、右に中身。変更はすぐ反映し、OK / キャンセルは置かない。設定の変更は曲の履歴に入れない。
- 開くと一番上の項目（一般）を出す。レイテンシの表示から開いたときだけ、オーディオを出す。
- マウスの割り当ては、ショートカットの中の「キーボード / マウス」の切り替えで出す。
- 画面に CLI の行は出さない（変更は CLI と同じコマンドを通る）。
- プルダウンは、アプリの共通のドロップダウン（ミキサーの「マスター ⌄」と同じ部品）を使う。
- 割り当ての衝突は、赤い文字と警告のアイコンで示す（縁は付けない）。キーの分類の色は、トラックの色を借りず、分類用の 5 色のトークンを使う。
- 入口は左のレールの一番下の歯車のアイコン 1 か所（前の入出力のプラグの形を替える）。上のバーには歯車を置かない。ほかに Ctrl+, とコマンドパレットから開く（2026-10-12、ユーザーの確認）。

- 設定のドロップダウンは通常の高さ 28、マウスの表のセルは列幅いっぱい・高さ 26。右に下向きの山形。長い名前は省略し、メニューはボタン以上の幅で下に開く。↑↓・Enter・Esc で操作する。スイッチは 34×20。
- ショートカットの分類はツール・再生・編集・トラック・表示の 5 色で、赤は衝突に使う。キーで検索を既定とし、名前検索へ切り替えられる。キーの絵は修飾キーに追従し、クリックで絞る。変更済みの行には点と戻す操作を出す。
- 衝突時は相手の名前と「入れ替え」「相手のキーを外す」を出す。プリセット変更・読み込み・書き出しなどの結果はトーストで示す。
- 編集の「ノートの重なりを防ぐ」「クリップの重なりを防ぐ」は、編集（動かす・伸ばす・貼る・描く・複製）のときだけ効き、録音で入るノートとクリップ（テイク）は切り詰めない（Studio Pro の No overlap と同じ）。同じテイクの組のクリップ同士も切らず、リップルで押された後ろのクリップは何も切らない（EDT-137〜EDT-139）。

## MP3 の書き出し（承認済み、2026-10-12）

- 形式に MP3 を足し、選ぶとビット深度の欄を畳んでビットレート（CBR、128 / 192 / 256 / 320 kbps）を出す。96 kHz は選べず、吹き出しで理由を出す。確認の窓は出さない。
- タグ（ID3）は曲名とトラック名から自動で入れ、入力欄は置かない。
- ラウドネスとトゥルーピークは書き出した MP3 の音で測り、ふつうの色で出す（-1.0 dBTP を超えた値の色分けはしない。入れるなら別に検討する）。
- LAME が読めないとき（消された・壊れた）だけ、書き出すボタンの左に理由を出し、MP3 だけを書き出せなくする。
- 「Xirius について」（Windows は左上のロゴ、Mac はアプリのメニュー、コマンドパレット）に、同梱したソフトのライセンスと LAME の LGPL の義務の 3 つを集める（LIC-015）。

## 触り心地の見直し 01〜09（承認済み、2026-10-13）

計画の項目は UI-117〜UI-127。

- 01 Ctrl の代わりの道具: 上のバーで「代わりの道具」（アレンジは範囲・分割・消しゴム・鉛筆・ミュート・試聴、ロールは鉛筆・消しゴム・分割・ミュート・試聴）を選ぶ。選んだものに青い下線を付け、Ctrl（Ctrl+Shift）を押している間は実際に効く道具を点灯する。ロールの既定は Ctrl が鉛筆、Ctrl+Shift が分割（UI-286）。
- 02 プラグインのスキャン: 一覧の先頭に「スキャン中 n / 総数」と進み具合の線と中止。読み込み中の項目は回転表示。読めなかったものは末尾の「使えないプラグイン」に理由つきで並べ、1 件ずつ再試行する。インストゥルメントの選択リストにも同じ行を出す。
- 03 下のバーのテンポと拍子（UI-300 で上のバーから移した）: テンポの数字は上下のドラッグ・ホイール・↑↓で動き、ダブルクリックか Enter で打ち込む。ホイールは 1 ノッチで 1、Shift で 10、Ctrl で 0.1。↑↓ は 1、Shift で 10。上下のドラッグは 1 px 0.5 BPM、Shift で 0.05 BPM（細かく）。拍子は押すと候補 7 つ（今のものに印）と分子・分母の入力が開く。
- 05a ロールで選んだノートは、強い文字色で塗る。
- 05b 時間の格子線は、小節線・拍線・細かい線の順に強くし、詰まったときは細かい線と拍線を間引いて小節線は残す。
- 05c ロールの鉛筆でクリップの外へ描くとクリップが伸び、外は暗く沈む。ルーラーの下側のクリップの帯の終端のつまみを引いて長さを変える。

## 音声の処理（承認済み、2026-10-13）

計画の項目は EDT-007・EDT-015・EDT-016・EDT-038・EXP-003・EXP-004 と、EDT-103〜111・KEY-046・CTX-080・EXP-047・EXP-048・UI-200。撮影の台本は `--script audioproc`。

- オーディオクリップの右クリック
  - 頭にテンポ・速さ・トランスポーズ・微調整の 4 つの欄と「曲のテンポに合わせる」。テンポが分からないとき・選んだクリップで値が違うときは「—」。
  - 欄は ↑↓ で 1、Shift+↑↓ で 12（トランスポーズ）か 10（テンポ・速さ・微調整）ずつ動き、すぐに効く。ホイールでも 1 ノッチで 1、Shift で 12 か 10、Ctrl で 0.1（テンポ・速さ）。Enter で打った値を入れ、Esc で閉じる（何も打っていなければ 1 回で閉じ、打ちかけなら捨てる。IME の組み立て中は IME に任せる）。
  - 残りは「処理 ›」（ノーマライズ・逆再生・テンポを検出）と「バウンス ›」（クリップをバウンス・新しいトラックにバウンス。範囲を選んでいるときは選択範囲をバウンス・新しいトラックにバウンス）。下のメニューはその場で開く。
  - Shift+F10 とアプリケーションキーで、選んだクリップのこのメニューが開く（並べ画面だけ）。
- 曲のテンポに合わせる
  - クリップごとに持つ。合わせたクリップは曲のテンポを変えると音が伸び縮みする。合わせないクリップは、終わりが音の長さに付いていく。
  - 伸縮は裏で先に作る。作っている間はクリップに % が出て、そのクリップは無音で鳴る。
  - 作れないときは「「名前」を伸縮できません（理由）」と［再試行］のトースト。理由にファイルのパスは出さない。
- 右端の Alt
  - 右端を Alt で引くと速さ（50〜200%）が変わり、クリップのテンポは残る。引いている間は「長さ 4.75 小節 速さ 84%」のように出る。
  - Alt で右端に重ねると、クリップの右端に伸縮の印が出る（カーソルの形は左右の矢印のまま。GPUI に伸縮のカーソルが無いため）。
  - 波形は速さに合わせて伸び縮みし、逆再生では後ろから描く。
- ノーマライズ・逆再生
  - ノーマライズはピーク 0 dB（設定は持たない）。上げた量（「+3.1 dB」）をクリップの中央の上に 1.6 秒出す。
  - 逆再生はファイルを書き換えない。キーは Alt+N・Ctrl+R（Logic・REAPER の割り当てでは Ctrl+R を付けない）。
- バウンス
  - クリップ（Ctrl+B）・新しいトラックに（Ctrl+Alt+B）・選択範囲（1 つにミックス、窓を出さない。新しいトラックにはトラックごとに 1 本）・トラック（トラックの右クリックの「新しいトラックにバウンス」）。
  - 裏で進み、進み具合と右下に止める四角を出す。新しいトラックへのバウンスは、作るトラックの行を先に下へ開き、そのクリップを左から埋める。その場のバウンスは元のクリップの上に出す。止めると行は閉じ、曲は元のまま。
- フリーズ
  - トラックの右クリックの「トラックをフリーズ」。フェーダーの手前で焼き、フリーズ中もボリューム・パン・センドは動く。
  - ミキサーでは名前の後ろに雪の印。インストゥルメントとインサートはすべて薄く鍵付きで、追加の行は出さない。
  - 編集しようとすると「フリーズ中のトラックは編集できません」と［フリーズを解除］のトースト。
- 取り込み
  - 置いた音声ファイルのテンポ（ファイル名などから）が曲と違えば、置いた 1 行のトーストに［曲のテンポに合わせる］。既定は合わせない。
- トースト
  - 処理のトーストはレーンの左下。ふつうの知らせは中央のまま。
- どの処理も 1 回の Ctrl+Z で戻る。

  - マクロはショートカット一覧の先頭の「マクロ」の組。行は名前・手順の数・キー。開くと手順（上へ・下へ・外す）と「コマンドを追加」「実行」が出る。

- 03 マウス（KEY-019・OPS-004）
  - 表の修飾キーの列は なし・Shift・Ctrl・Ctrl+Shift・Alt・Ctrl+Alt。「一時的なツールの切り替え」はツールごとの行で、修飾キー → 切り替え先。ツールの追加・削除・元に戻すができる。
  - すでに使っている修飾キーへ移すと保存せず、その行の下に理由を出す。切り替えが同じ修飾キーのクリックを隠すときは行に印を出す。
  - 一時ツールの保管場所はマウスの表だけ（設定 `edit.arrow.alternative-tool` は無くした。古いファイルは黙って読み捨てる）。
  - 一時ツールが入るセルは青い字の「ツール名（一時的）」。列に入らないときは末尾を「…」にし、ツールチップに全部を出す。
- 04 キーのプリセット（KEY-012）
  - プリセットを替えても、自分で変えた行は残る（トーストに「変更済みの N 件はそのまま」と取り消す）。「…」のメニューの「すべてプリセットに戻す」で全部を戻す。
- 05 共通（SET-001）
  - ショートカットとマウスの行に内部名（`note.delete` など）は出さない。ツールチップにだけ出す。
  - アレンジのクリップのクオンタイズ（`clip.quantize`・Q）。下のオートメーションも一緒に動く。

## ドラムの見方（承認済み、2026-10-14）

計画の項目は EDT-006・EDT-058。撮影の台本は `--script drum-view`。

- 切り替えはドロワーのバー、「ピアノロール」「ミキサー」のタブの右。「鍵盤｜ドラム」の 2 つ組（選んでいる側が塗り）と、ドラムのときだけ「GM ドラム ▾」のボタンが出る。右端の「トラック / クリップ」の名前はその右に詰める。
  - 見方はパートごとに覚え、ドラムマップはトラックごとに覚える（履歴には入れない。コマンドは `roll.view`）。選んでいないパートは、ドラムのアイコンか、楽器が Drum の名前のトラックならドラムで開く。
  - 「GM ドラム ▾」を押すとマップの一覧（GM ドラム・ドラムキット）が開き、使っているものにチェックが付く。
- ドラムの表示

  - 行は高いほうが上で、ノートの無い音の行は出さない。マップに無い音がパートにあるときは「ノート 90」のような行を足して、ノートを隠さない。切り替えた直後は、ノートのある行がグリッドの真ん中に来る（ノートが無ければキックの行が見える所まで）。
  - ノートは行の高さのひし形で、始まりの位置が中心。長さの端は無く、押す所はどこでも「動かす」。上下に動かすと、鍵盤の半音ではなく行を 1 つずつ動く。

  - ノートのある行は隠せない（淡色。ノートを隠さない決まりのため）。どれもトラックごとに覚え、履歴には入れない（コマンドは `roll.drum.hide`・`roll.drum.move`・`roll.drum.rename`・`roll.drum.reset`）。
  - 撮影は `--script drum-view` の dv05・dv06 と、`--script drum-rows`（2 つのメニューと、行のメニューで上へ移動した後）。
- インストゥルメントの音名（EDT-134）

## 最初の画面とはじめての起動（承認済み、2026-10-14）

計画の項目は UI-070・UI-077・UI-078・UI-260・UI-261・UI-262・UI-263・PLG-059・LIC-016。撮影の台本は `--script startup`。

- 起動する曲
  - はじめての起動は空の曲（入口）で開く。案内の窓や手順の窓は出さない。2 回目からは前回閉じた曲（サンプルの曲・新しい曲を含む）で開く。
  - テンプレートは無い。新しい曲は曲名のメニューの「新規」（Ctrl+N）で、空の曲の入口に戻る。
- 空の曲の入口（本体の真ん中の 1 列）
  - 上から、入口の 3 つ（オーディオを録音・MIDI を演奏・ファイルをドロップ）、装置の欄、「最近の曲」の一覧。
  - 入口やドロップで作ったトラックには、作った順に識別色の一覧から色が付き、使っている色は飛ばす。本数に上限は無い。
- 装置の欄（幅 560px の面。行は 4 つ、左にアイコン）
  - 出力の行: 装置の名前のボタン（押すとすべての装置の一覧。行の右に「入力 n · 出力 n」、使っている装置にチェック）・「48 kHz · 6.8 ms」のようなサンプルレートとレイテンシ・「テスト音」・出力の左右のメーター。
  - 入力の行: 入力ごとの札とメーター。入力の無い装置では「入力なし」。
  - MIDI の行: 先頭に「PC のキーボード」、続けて MIDI のポート。受けると点が光る。
  - プラグインの行: 「プラグイン n」。スキャン中は「プラグイン n / 総数」とバー、読み込めない物があればその数を警告の色で。
  - 装置が 1 つも無いときは「オーディオデバイスなし」と出し、テスト音を出さない。装置の一覧も「オーディオデバイスなし」の 1 行だけ（押せない）。
  - 装置は自分で選ぶ。既定の出力の装置に入力があればそれ、無ければ入力と出力を両方持つ装置。2 回目からは前に選んだ装置。
- 「オーディオを録音」を入力の無い装置で押すと、トラックを作らず、入口の下に入力のある装置の一覧を開く。選ぶとその装置に替え、録音準備のオーディオのトラックを作る。
- 「MIDI を演奏」は録音準備のインストゥルメントトラックを作り、PC のキーボードで弾けるようにする。
- テスト音は押したときだけ、左 → 右の順に −18 dBFS の短い音を鳴らす。鳴っているあいだはボタンが点き、欄の出力のメーターが振れる。設定のオーディオのページの出力の行にも同じボタンがある。
- 最近の曲: 見出し「最近の曲」の下に、新しい順に 5 曲まで（今開いている曲は除く）。行は曲の名前と開いた時刻。最後にサンプルの曲が「サンプル」の印付きで並ぶ。押すとその曲を開く。
- 設定の MIDI の入力の一覧は、ポートが無くても先頭に「PC のキーボード」が出る。弾くと点が光り、音名が出る。切ると PC のキーで弾けなくなる。
- MIDI の鍵盤と PC のキーボードは、録音準備のインストゥルメントトラックだけを鳴らす（トラックの入力の絞り込みは今のまま。録音中の thru も同じ集合）（REC-024、Studio Pro の「Instrument Input Follows Selection」と同じ）。
  - 設定の MIDI の「インストゥルメントの入力を選択に合わせる」（`midi.follow-selection`、既定で入）が入のとき、インストゥルメントトラックを選ぶと、そのトラックを録音準備とモニターにし、ほかのインストゥルメントトラックの録音準備とモニターを外す（オーディオトラックは触らない）。この変化は選択に付随する状態として扱い、取り消しの履歴には積まない。選んだトラックがオーディオトラックや無選択なら、録音準備はそのまま。
  - 切のときは選択で録音準備を変えず、録音準備のインストゥルメントトラックだけが鳴る。手で録音準備ボタンを押して複数を録音準備にするのは、入のままでもできる（次に選択を移したときに 1 本に戻る）。
  - フリーズ中のインストゥルメントトラックは、選んでも録音準備・モニターにしない（ほかのトラックの録音準備もそのまま）。録音準備のフリーズ中のトラックは録音から外し、「<名前> はフリーズ中のため録音しません」と言う（ほかのトラックのテイクは入る）（REC-025）。
- プラグインのスキャン: はじめての起動で裏で始まり、待たせない。設定のプラグインのページの見出しの右に「n / 総数」とバー、その右に開いているファイル（長いパスは頭を「…」で切る）。一覧の先頭の行はスピナー・「スキャン中」・「中止」。
- 「Xirius について」
  - 版の下に「リポジトリ」のボタン。押すとブラウザーで https://github.com/tekalu1/xirius を開く。寄付のリンクは寄付先が決まるまで出さない。
  - 新しい版があるときは、版の行が「バージョン 1.0.0」・新しい版の番号（下向きの矢印の札）・「ダウンロード」（塗りのボタン。リリースのページを開く）になり、その下の面に新しい版の番号と変更点の箇条書きが出る（長い行は折り返す）。
- 更新の確かめ
  - 起動のあと 1 日 1 回、GitHub のリリースを窓のスレッドの外で確かめる。取れないときは何も出さない。
  - 新しい版があると、トップバーのロゴの右上に塗りの色の点が付く（ロゴはどの幅でも出る。UI-300）。
  - 一般の設定の末尾の「更新」の組に「更新を確認」のスイッチ（右に「起動時」）。既定で入。切ると問い合わせず、点も消える。

## 範囲のトリムと変形の枠（承認済み、2026-10-13）

計画の項目は AUT-010。撮影の台本は `--script range-trim`。

- 範囲の上半分
  - オートメーションレーンかテンポの行に範囲があるとき、範囲の上半分にポインターを載せると上下の矢印になる。下半分はこれまでどおり（範囲を動かす・選び直す）。
  - 上下にドラッグすると、範囲の中の値がまとめて上下し、ドラッグ中は動いた後の線と「+12 %」「-20 %」「+8 BPM」の吹き出しが出る。Shift で 1/10 の細かさ。範囲の端には元の値の点を残し、外の線は変わらない。
  - 離すと 1 回の操作で残り、範囲はそのまま残る（続けて動かせる）。
- 変形の枠
  - Alt+T か、範囲の右クリック「範囲をトランスフォーム」の先頭「自由変形」で、ポインターの下のレーン（またはテンポの行）の範囲の値を囲む枠が出る。枠は上辺と左右の辺の細い線で、上辺の真ん中と右上の角に四角の取っ手。
  - 上辺の取っ手を上下にドラッグすると縮尺（吹き出しは「縮尺 153%」）、角の取っ手は傾き（「傾き -30 %」）。離しても枠は残り、次の取っ手を続けて使える。
  - Esc か、枠の外（ほかのトラックのクリップなど）を押すと枠が消える。
- 波を描くときの修飾キー
  - 承認済み（2026-10-15）: 描く道具（鉛筆）で波（サイン波・三角波・矩形波・ノコギリ波）をドラッグしている間だけ、Mod を押して動かした分が波の位相になる（描く範囲の両端は動かない）。Mod+Alt を押して動かした分は、描く範囲ごと時間をずらす。
  - 押した時点で Mod を押しているときは、これまでどおり矢印に替わる（描かない）。直線・放物線・フリーハンドは Mod を読まない。
  - Alt だけで離すと、これまでどおり描いた範囲が 1 周期。Mod+Alt で離したときは 1 周期にしない。
  - 撮影は `--script wave-mod`（描いた波・Mod で位相・Mod+Alt で時間のずらし・離した後）。

## 書き出しと取り込み 1.0（承認済み、2026-10-14）

計画の項目は EXP-019〜023・EXP-026・CTX-057（MIDI の行）・CTX-060・UI-280・UI-281・EXP-006・EXP-007・PLG-040。撮影の台本は `--script export-v1` と `--script dawproject`。

- 古さ: 書き出したときのトラックとバスごとの指紋を曲のフォルダーの `exports/` の記録に残し、開き直しても印が残る。元に戻せば新しいに戻る。
  - カードには変わったトラックの色の点だけ（文字なし）。名前はポインターを載せたときの吹き出し。ステムのファイルの行にも時計の印と点が出る。
  - 変わったトラックがセンドしているバスのステムも古くなる（その行の点はセンドの元のトラック）。
  - 「更新」は古いファイルだけを書き直し、ほかのファイルはそのまま。
- 同じ種類・同じファイル名の書き出しは、前のファイルをごみ箱へ送って同じ名前で書き、一覧の行を置き換える。
- MIDI はパネルの 3 つ目の種類「MIDI」。インストゥルメントトラックだけが並び、「1 つにまとめる」（既定）か「トラックごと」。カードは聴けない。
  - MIDI のクリップの右クリックの「MIDI ファイルとして書き出す…」は、そのクリップの範囲とトラックを選んで開く。トラックの右クリックの「書き出す」の下に「このトラックのステム…」と「MIDI ファイル…」（オーディオのトラックでは淡い）。
- 「曲に取り込む」（カードのボタン・カードと行の右クリック）は、書き出した範囲の頭に新しいトラックとして置く。
- DAWproject は曲名のメニュー。
  - 「DAWproject として書き出す…」は OS の保存の窓で場所を決め、音のファイルを中に入れる。左下に「DAWproject を書き出しています N%」、終わると「含めなかったもの N」（押すと一覧）と「フォルダーを開く」。同じ名前のファイルはごみ箱へ。
  - 「DAWproject を開く…」（「開く…」はフォルダーを選ぶ窓なので、ファイルを選ぶ行を別に置く）と、窓へのドロップ（「<名前> を開く」の枠）で、新しい曲として開く（まだ保存していない）。読む間は「読み込んでいます N%」、読めなかったものがあれば「読み込めなかったもの N」と「見る」で一覧。
  - 一覧は件数を右に寄せ、12 行を超えるとスクロールする。
- `docs/design-rules.md` に合わせてモックから変えたところ: ファイルの行の頭のトラックの色は点（モックは細い帯）、古いファイルの LUFS と待っているファイルの名前は本文の文字色（モックは不透明度）、ドロップの「<名前> を開く」は半透明の幕の中の不透明な下地の上。
- 残り: ARA の解析を待つ書き出し（ENG-025。ARA のホストが無い）、別の DAW で開くことと、Bitwig・Studio One 6.5 以降が書いたファイルでの確かめ（EXP-006・EXP-007）。

## 編集の手触りの残り（承認済み、2026-10-15）

- 承認済み（2026-10-15）: オートメーションが Read で、レーンに点があるノブは動かせない。ポインターを重ねるとツールチップに「オートメーション（Read）のため変更できません」、ポインターは禁止の形、右クリックのメニューの値を変える行は灰色。Touch・Latch は掴んでいる間だけ書くので動かせる。Read でもレーンに点が無ければ動く（UI-063）。
- 承認済み（2026-10-15）: クリップの右端の下 10 px はループの角。ドラッグでループの長さ、Alt でループの頭が変わる。上の残りは今までどおりトリム（EDT-041）。
- 承認済み（2026-10-15）: ピアノロールの ← → は、ノートを選んでいれば 1/16 ずつ動かし（1 つの履歴）、選んでいなければ選択を隣へ移す（UI-088）。

## クリップのトランスポーズ（承認済み、2026-10-22）

モックは `temporary/research/2026-10-22/mockups/waveform-transpose-inspector.html` の 02。計画の項目は UI-311。

- MIDI クリップはトランスポーズの値（±24 半音）を持つ。ノートは書き換えず、鳴らすときに足す。0 に戻せば元のキーになる。範囲の外の値は丸める。
- 右クリックメニューの頭の欄は、オーディオのクリップと同じ値の欄にする（− ＋ ✓ はやめる）。欄はクリップの今の値を出す。↑↓ で 1、Shift+↑↓ で 12、打った値は Enter で入る。0 と違う値でもメニューは開いたままで、クリップがその場で変わる。欄の名前は切れない幅（92 px。モックの名前の 84 px と、その左の 8 px）にする。
- オーディオと MIDI のクリップを混ぜて選んだときも、この欄を出す。値が揃っていなければ「—」で、入れた値は選んだ全部に付く（ほかの欄と同じ）。
- メニューを開くと、トランスポーズの欄（無ければ最初の値の欄）がキーを持つ（キャレットと縁がその欄に出る）。「トランスポーズ」の札を押しても欄にキーが移り、検索の箱を押すとキーは検索へ移る。数字・符号・↑↓は欄が受け、ひらがな・英字は検索の箱へ渡す（名前で探せる）。IME の組み立て中の字は欄が持ち、検索の箱には入れない。全角の「０-９」「＋」「－」「ー」「．」は半角として受ける（UI-313）。
- 値は「+2」「−12」のように符号付きの数だけを出し、横に単位の文字を置かない（0 は「0」、負は U+2212 の「−」）。読み上げの名前には「トランスポーズ +2 半音」のように単位を付ける。オーディオのクリップのメニューからも「半音」「BPM」「セント」の文字を消す（速さは「100%」と値の中に % を含める）。
- 値が 0 でないときは、クリップの名前の右に「+2」の印を出す。オーディオのクリップの印と同じ形（淡い地の小さな角丸に、符号付きの数）で、負は同じ「−」にする。
- メニューの「クオンタイズ」の中に「トランスポーズをノートに反映」を置く（欄のすぐ下には置かない。UI-313）。押すと、クリップの値をノートに足し、値を 0 に戻す（鳴る高さは変わらない）。値が 0 のときは押せない。1 回の取り消しで、ノートと値の両方が戻る。ノートがキーボードの外（0〜127 の外）へ出る場合は反映せず、理由を出す。
- ピアノロールは書いたままの高さで描く（値は描く高さに掛けない）。ピアノロールの試聴は鳴る高さ（値を足した高さ）で鳴らす。
- 再生・書き出し・バウンス・フリーズ・MIDI ファイルの書き出しは、値を足した高さで鳴らす（書き出す）。0〜127 の外のノートは鳴らさない。
- 保存の互換: 値の無い古い曲は 0 として読む。値が 0 のクリップは保存の形を変えない。複製・分割・貼り付け・結合でも値を引き継ぐ（結合はノートに足して 0 にする）。DAWproject には値を置く所が無いので、書き出すときにノートへ足す（合わせて 0 のクリップとして読み戻す）。
- 値を読む・書く入口は `clip.transpose`（`--semis` で設定、`--by` で変化量。オーディオと MIDI の両方）と `clip.transpose.write`（ノートに反映する）の 2 つにまとめる。あとでインスペクターも同じコマンドを使う。`clip.transpose` の `--semis` は schema に −24〜24 を出し、範囲の外は丸める。`clip.transpose.write` は、反映した後の高さが 0〜127 の外に出るノートがあると何も変えずに失敗する。

- トラックの頭の印（UI-312）: トランスポーズかベロシティが 0 でないとき、名前の右に 1 つの印を出す。形はクリップの印と同じ淡い地の小さな角丸。名前の場所は、実測が全角 3 文字ぶん（約 42px）より短ければその実測ぶん、長ければ全角 3 文字ぶんを取り、入りきらない名前は「…」で切る（名前が「…」だけになることはない）。印は、名前の場所を取った残りに収まる形を長い順に選ぶ。全部の形（「−12 +10%」）、1 つだけの形（トランスポーズが 0 でなければその値、0 ならベロシティの値）、どちらも入らなければ値があることだけを示す小さな点（約 10px）。印の範囲（描く所・当たりの判定・名前を打つ欄）は同じ矩形を使い、どの形でも指を載せると「トランスポーズ −12・ベロシティ +10%」のように 2 つの値を全部出す（0 の項目は出さない）。
- 広げるボタンの名前（UI-312）: 「トラックの詳細を表示」を「トラックを広げる」にする。
- 入口（UI-312）: トラックの値は `track.transpose`（`--semis`、±64）と `track.velocity`（`--percent`、±100）。schema に範囲を出し、範囲の外は丸める。CLI と MCP からも使え、1 回の取り消しで戻る。
- 互換（UI-312）: 値の無い古い曲は 0 として読む。0 のトラックは保存の形を変えない。範囲の外の値は読みで丸める。トラックの複製では値を写す。DAWproject には値を置く所が無いので、書き出すときにノートの高さと強さへ掛ける（クリップのトランスポーズと同じ扱い）。

## アプリの中の更新（承認待ち、2026-10-22）

- 「Xirius について」の更新の知らせは、今までどおり版の行に新しいバージョンの札を出す。行の右のボタンは 1 つだけで、そのときの状態を言い、次へ進める。
  - まだ何もしていないときは「ダウンロード」。押すと、裏でマニフェスト・署名・SHA256SUMS・setup.exe を取り、署名と版と SHA を確かめる。

  - 確かめ終わると「更新して再起動」。押すと終了の流れ（保存していない曲は今までどおり書き出す）を通り、Xirius が終わった後に setup.exe を `/S /XRUN` で起こし、入れ替えの後で Xirius を起動し直す。押さなければ何も入れない。
  - 確かめたインストーラーは次に起動したときも残っていて、すぐ「更新して再起動」を出す（もう一度ダウンロードしない）。

  - 前回の起動でインストーラーが止まっていたときは、そのことを警告の色で出し、「Release のページを開く」を置く。
- 次のときは、更新を入れずに、これまでどおり「ダウンロード」で Release のページをブラウザーで開く。
  - アプリに本物の公開鍵が入っていない（仮の鍵のビルド）。
  - インストーラーが入れた場所以外から動いている（zip を展開して使っている）。入れた場所は HKCU の `InstallLocation` で見る。

## 複数のトラックの選択とまとめての変更（承認済み、2026-10-24）

元は案の資料 `multi-select/report.md` の §3・§4 とそのモック。計画の項目は UI-340・MIX-050・CLI-003。

- 選択は 1 つ（UI-340）: トラックの頭とミキサーのストリップは、同じ 1 つの選択を見る。選択は起点（anchor）と今の位置（focus）を持ち、インスペクターなど 1 本だけを見るものは focus を見る。
- クリック（UI-340）: ふつうのクリックは 1 本を選ぶ（起点もそこ）。Ctrl クリックは 1 本の足し引き（最後の 1 本は外れない）。Shift クリックは起点からの範囲（フォルダーをまたぐ範囲は、間のフォルダーとその中のトラックも入る）。Ctrl+Shift クリックは範囲を今の選択に足す。頭でもストリップの名前と地でも同じ。選んだ行を押してドラッグせずに離すと、その 1 本だけになる（ドラッグなら選んだ全部を運ぶ）。
- キー（UI-340）: 頭にフォーカスがあるとき、↑↓ は隣の 1 本を選び、Shift+↑↓ は起点から広げ・縮める。Ctrl+A はトラックのすべてを選ぶ（focus は動かない）。レーンにフォーカスがあるときの Ctrl+A は今までどおりクリップのすべて。M・S などトラックを取るコマンドは、選んだ全部に効く。
- 見た目（UI-340）: 選んだ頭とストリップの面は、新しいトークン `surface_track_sel`（ダーク `#41434c`・ライト `#c9cdda`。`surface_clip_sel` と同じ値）で塗る。フェーダーのつまみの面（`surface_thumb`）とは別の色。1 本でも複数でも同じ色で、線・片側の色は使わない。頭の空いた所のダブルクリックでストリップを 1 秒ほど光らせる面は、選んだ面の上で見えるように別のトークン `surface_strip_flash`（ダーク `#50535e`・ライト `#b3b8c8`。選んだ面から L* で 5 以上離す）で塗る。
- 読み上げ（UI-340）: トラックの木は multiselectable で、選んだ行の全部が selected。
- 差を保って動かす（MIX-050）: 選んだトラックのフェーダーとパンを動かすと、押した瞬間の値からのずれを選んだ全部に足す。端（+12 dB・−∞、L100・R100）に着いたトラックだけそこで止まり、戻すと差も戻る。フェーダーは −60 dB 以下を −∞（無音。表示も「-∞」）とする: ずれで −60 dB 以下になったトラックは −∞ になり、引いたフェーダーを −60 dB 以下（下の端）まで下げると選んだ全部が −∞ になる。−∞ のトラックは動かず、−∞ から上げるドラッグはそのトラックだけを動かす。Studio Pro の手引きに複数選択で −∞ を含む場合の記述が見つからなかったので、見直しの案どおりにした。Shift のドラッグは今までどおり 0.25 倍。
- Alt（MIX-050）: Alt を押したまま押すと、どのつまみとボタン（フェーダー・パン・M・S・録音）も、そのトラックだけを変える。選択はそのまま。
- 選んでいないトラック（MIX-050）: つまみとボタン、インサート・センド・入出力の欄は、そのトラックだけを変え、選択を変えない（右クリックのメニューも同じ。M・S・録音の上の右クリックも選ばない）。選ぶのはストリップの名前と地を押したときだけ。
- ドラッグの途中（MIX-050）: undo・redo・履歴の移動・曲の差し替えは、つかんでいるフェーダーやパンを手放す（離したときのコマンドは出ない）。レーンのオートメーションが持つトラックは、ドラッグ中も動かず、表示も今の値のまま。
- コントローラーのつまみ（MIX-050・OPS-007）: つまみを割り当てたトラックが画面で選ばれていると、つまみは選んだ全部を差を保って動かす。選ばれていなければ、そのトラックだけ。
- メニュー（MIX-050）: 選んだトラックのフェーダーとパンのメニューの「戻す」「値を入力…」は、選んだ全部に同じ値を入れる（そろえたいときの道）。
- 取り消し（MIX-050・CLI-003）: 1 回のドラッグ・1 回の押下・1 回のメニューは、何本に効いても 1 コマンドで、取り消しは 1 回で戻る。差を保つドラッグは、離したときに `track.volume.set --by <dB>` か `track.pan.set --by <量>` の 1 コマンドになる。
- CLI（CLI-003）: `track.volume.set` と `track.pan.set` に `--by` を足す。それぞれのトラックの今の値にずれを足し、範囲の端で止める（ボリュームは −60 dB 以下を −∞ にし、−∞ のトラックは動かさない）。`--db`・`--pan` と `--by` はどちらか 1 つ。`--by` の単位は `--db`・`--pan` と同じ。

# ARA のホストの検証表（PLG-038・PLG-049）

ARA のホスト（`docs/ara-host.md`）を、SDK の試験用のプラグインと本物の ARA のプラグインで確かめた結果。対象は少数に絞る（PLG-049）: SDK の TestPlugIn、Melodyne、VOCALOID。Gliss は手元に無く、確かめていない。

試験の音は、試験の中で作った音（220・247・262・294 Hz の正弦波を 0.6 秒ずつ、間に 0.4 秒の無音を挟んで並べた 4 秒、48 kHz）。利用者の曲は使わない。どのプラグインも、試験の間に窓（認証・編集の窓を含む）を出さなかった。

## 手順

| 手順 | 試験 | 環境変数 |
| --- | --- | --- |
| TestPlugIn の通し | `cargo test -p xirius-ara --test test_plugin -- --ignored` | `XIRIUS_ARA_TEST_PLUGIN` に `ARATestPlugIn.vst3` |
| 本物のプラグインの通し | `cargo test -p xirius-session --test ara_real -- --ignored` | `XIRIUS_ARA_REAL_PLUGIN` に ARA の VST3 の束 |

どちらも `#[ignore]` で CI では流れず、Release の前に `python scripts/ci_tests.py --plugins` で流す。環境変数が無い・ファイルが無いときは失敗する（飛ばして通ったことにしない）。`ara_real` は 2 つに分かれる。

1. 文書の層: 読み込み → 解析の終わりを待つ → 音符を読む → 描いた音の大きさ → archive を取る → 同じ archive で 2 つ目の文書を開き、音と音符が戻り、開いただけで「変わった」にならないこと。
2. 曲の層（ユーザーの手順）: クリップに付ける（`clip.ara.attach`）→ 解析 → 再生（描いた音が鳴る・再生で曲が変わらない）→ 保存して開き直す（別の曲のレート 44.1 kHz で開き直し、archive が曲から戻る・編集が残って鳴る・開いただけで曲が変わらない）→ 外す（`clip.ara.detach`。元の音に戻り、文書が畳まれる）。

## 結果

プラグインの版はここに書かない（開発に使った PC の入っている物の一覧にしないため）。確かめた版は Release の記録に残す。

| 対象 | 文書の層 | 曲の層 | 落ち方 |
| --- | --- | --- | --- |
| SDK の TestPlugIn（ARA SDK 2.3） | 全項目が通る（プラグインの中の assert 0） | — | 無し |
| Melodyne | 通る | 5 段とも通る | 無し（直した後） |
| VOCALOID Bridge | 読み込み・解析・archive の戻しは通る。音は無音 | 再生で止まる（無音） | 無し |
| VOCALOID VSTi | ARA の工場が無い（ARA のプラグインではない） | — | — |
| Gliss | 手元に無い | — | — |

### TestPlugIn

読み込み・解析・音符・再生の範囲の音・範囲の移動・保存と復元・別のレート（44.1 kHz）の音源・解析の待ち・畳むまでを通し、プラグインの中の assert が 1 つも起きないことを確かめた。

### Melodyne

- 文書の層: 解析は約 1〜2 秒で済み、音符は 4 つ（最初の音符は 220 Hz 近く）。描いた音の大きさ（RMS 0.219）は元の音と同じ。archive は約 48 KB。2 つ目の文書で戻すと、音と音符が同じで、「変わった」にならない。
- 曲の層: 付けてから解析の終わりまで約 0.4 秒。再生の音（RMS 0.155。描いた範囲の半分がクリップで、0.219 の 1/√2）は描いた音と合い、再生で曲は変わらない。保存して開き直すと（別の曲のレート 44.1 kHz で開き直す）archive が曲から戻り、同じ音が鳴り（RMS 0.155）、開いただけで曲は変わらない。外すと元の音に戻り、文書は 0 になる。
- 見つけたこと: Melodyne は最初の文書を作ったスレッドに結び付いていて、別のスレッドで 2 つ目の文書を作ると中でアクセス違反が起きた。OLE の初期化と窓のメッセージを回すだけでは直らず、プラグインごとに 1 本の ARA のスレッドに文書を集めて直した（`docs/ara-host.md` の 4）。直す前のこの落ち方は、囲い（PLG-058）がプロセスを落とさずに止めた。

### VOCALOID

- ARA の工場を持つのは `VOCALOIDBridge.vst3` だけ。読み込み・解析（約 0.2 秒）・archive の取り出しと戻しは通り、開いただけで「変わった」にならない。
- 音符は 0、描いた音は無音、archive は空。声は VOCALOID のエディターで作ってプラグインに渡す作りで、エディター無しでは鳴らない。曲の層は「プラグインが無音を返した」で止まる（Xirius の不具合ではない）。
- 試験の後、プロセスの終わりに時間がかかることがあった（残ったプロセスは無い）。

# 組み込みの楽器

Sampler（PLG-067）と Drum Kit（PLG-068）の値と、曲の形式でのしまい方。ほかの組み込みの装置（EQ・Compressor ほか）と同じく、値は曲の中の `Plugin.params`（0..1 に正規化した値）に、読むファイルは `Plugin.samples` に入る。曲の形式の版は上げていない。

## 音の部品（両方で同じ）

Sampler と Drum Kit は同じ声（`crates/xirius-engine/src/stock/voice.rs`）で鳴る。声の値は次の 13 個。

| id | 名前 | 範囲 |
|---|---|---|
| `attack` `decay` `release` | エンベロープ | ms |
| `sustain` | エンベロープ | % |
| `ftype` | フィルターの型 | LP・BP・HP |
| `cutoff` `resonance` `drive` | フィルター | Hz・%・% |
| `transpose` `fine` | 音の高さ | 半音（±48）・セント（±100） |
| `volume` `pan` `velocity` | アンプ | dB・パン・ベロシティの効き % |

サンプルの鳴らし方は次の 8 個。開始・終わり・ループの位置はファイルの長さに対する割合。

| id | 名前 |
|---|---|
| `start` `end` | 鳴らす範囲 |
| `loop` `loop_start` `loop_end` `xfade` | ループと、その継ぎ目のクロスフェード |
| `reverse` `normalize` | 逆再生・ノーマライズ |

## Sampler

- 声の 13 個は楽器に 1 組（画面ではエンベロープ・フィルター・アンプを 1 回だけ出す）。キーは id のまま（`cutoff`）。
- サンプルの鳴らし方の 8 個はゾーン（ファイル）ごと。キーは `file<n>.<id>`（`n` は `samples` の 1 から数えた位置。例: `file2.loop_start`）。

## Drum Kit

- バンク A–H × 16 = 128 パッド（A1..H16）。パッド `i` はノート 36 + `i` で鳴る（127 を超えると 0 から数え直す。F13 = ノート 0）。
- 楽器に 1 つ: `volume`。
- パッドごと（キーは `<パッド>.<id>`。例: `A1.cutoff`、`B5.choke`）: 声の 13 個、サンプルの鳴らし方の 8 個、それに次の 5 個。
  - `layer_mode`: レイヤーの選び方（Velocity・Round Robin・Random・Stack）。
  - `trigger`: One Shot・Loop・Normal・Toggle。
  - `choke`: None・Self・1–32。
  - `mute`・`solo`。
- ファイルごと（キーは `file<n>.<id>`）: `pad`（そのファイルが鳴るパッド）と `top`（Velocity のときのレイヤーの上端、1–127）。
  - `file<n>.pad` が無いファイルは、`n` 番目のパッドで鳴る。ファイルを足す・外すコマンドは、どのファイルにも `pad` を書いてから並べ替えるので、ほかのファイルのパッドは動かない。
  - 1 つのパッドに載ったファイルがそのパッドのレイヤー。順はファイルの並び順。

## しまい方の決まり

- 値は既定と同じでも書いてよく、無いキーは既定の値になる。`plugin.param.list` は、ファイルごと・パッドごとのキーを書いてあるものだけ出す。
- ファイルを外すと、そのファイルの `file<n>.*` は消え、後ろのファイルの `file<n>.*` は 1 つずつ詰まる。ファイルの並びと値は 1 つの変更で動き、元に戻す・やり直すも 1 回で戻る。
- 曲を保存すると、`samples` のファイルはクリップの音と同じく曲のフォルダーに集まり、曲のフォルダーからの相対のパスになる（ENG-077）。
- プリセット（`.xpreset`）は `params` のすべてのキーと `samples` を持つ。読むと、つまみの値に加えて、ゾーンごと・パッドごとの値とサンプルも戻る。
  - サンプルは、プリセットのフォルダーの `samples/` に写して持つ。名前は `<元の名前>-<中身の sha256 の先頭 16 桁>.<拡張子>` で、プリセットには `preset:samples/<名前>`（プリセットのフォルダーからの相対）と書く。同じ音は 1 つの写しになり、同じ名前の違う音は別の写しになる。曲のフォルダーや人のフォルダーのパスは書かないので、サンプルを動かしても、プリセットのフォルダーを別の PC へ写しても鳴る。保存のときにディスクに無いサンプルは、ファイルの名前だけを書く。
  - 読むときは、書いた所（写し、曲のフォルダーからの相対、前の版の絶対のパス）を見て、無ければ同じ名前のファイル（大文字・小文字は問わない）を、曲のフォルダー（4 段の下まで）、プリセットのファイルのあるフォルダー、プリセットの `samples/` の順に探す。見つかった所は曲のファイルと同じ書き方（曲のフォルダーの中なら相対）で入る。
  - どこにも無いサンプルは、そのファイルのゾーンの値（`file<n>.*`）と一緒に外し、後ろのファイルの値は詰める（ファイルを外すのと同じ）。外したことはファイルの名前で返す（「サンプルが見つからないため外しました」）。Drum Kit では、残るファイルは今のパッドに留まる。
  - `samples` を持たない前の版のプリセットは、ファイルに触らない。ファイルとパッドの並び（`file<n>.*`）とパッドの値（`A1.choke` ほか）は今のまま残し、機器の値だけを入れる。
  - 画面（窓の一覧・‹ ›・ブラウザー）も CLI・MCP と同じ `preset.load` を通るので、どの道でも同じに戻る。値・サンプル・プリセットの名前が 1 つの変更で入り、元に戻すも 1 回。
  - `Default` は機器の出荷の形で、サンプルも空にする。
  - 保存していない曲で相対のパスのサンプルは、無いとは決められないので、探さずにそのまま入れる。
  - ブラウザーから、その機器の無いトラックへ読むと、機器を足すのとプリセットが 1 つの変更になる（`preset.load` の `device`）。トラックの無い所へ読むと、トラックを作る変更とプリセットの 2 つになる。

## 古い曲

- PLG-067・PLG-068 の前の曲は、そのまま開ける。開いただけでは変更あり（dirty）にならない。
- 前の Sampler の `sound`・`tune`、前の Drum Kit の `kit`・`tune`・`decay`・`velocity`・`kick`・`snare`・`hats`・`toms`・`cymbals`・`percussion`（合成の音色の値）は、使わなくなったキー（`BuiltinDef::retired`）。曲には書いたまま残り、音にもエラーにも出ない。合成の音色はもう無いので、声の値は既定から始まる。

## サンプルが無い間

- サンプルが 1 つも無い Sampler・Drum Kit は、楽器の無いトラックと同じ仮の音（Sampler は音程のある音、Drum Kit は打つ音）で鳴る。「MIDI を演奏」や MIDI ファイルの読み込みで作ったトラックが、サンプルを入れる前から鳴るように。
- 最初のファイルが入ると楽器の音に替わり、すべてを外すと仮の音に戻る。仮の音は楽器の値（エンベロープ・フィルターほか）を使わない。

## 画面（UI-333・UI-334）

形は devices-v2 のモック（`docs/ui-approved.md` の「内蔵の機器の窓とプリセット」）。窓の中身は `crates/xirius-ui/src/device/sampler.rs`、窓の押す所は `crates/xirius-ui/src/instrument/spots.rs`。

- サンプルが 1 つも無い間は、つまみを出さず、ドロップの面（「Drop samples here」と「Browse」）だけを出す。Browse はブラウザーのファイルのタブを開く。最初のファイルが入ると窓が伸びて、サンプルの段と声のつまみが出る。
- Sampler: 上にサンプルの段（‹ 名前 ›、Loop・Reverse・Normalize、Loop が入っている間だけ Loop の後に小さい X-Fade のつまみ（大きさ 20、名前・つまみ・値の横並び）、波形と開始・終わりの点。Drum Kit も同じ）、その下に Env・Filter・Amp、鍵盤の上にゾーンの帯。ゾーンを押すとそのファイルを選び、サンプルの段とつまみはそのファイルの `file<n>.*` を指す。選んだゾーンは窓を開いている間だけ覚え、曲にも履歴にも入れない。根音が同じゾーン（名前に音名の無いファイルはどれも C3）は同じ場所を横に分け合い、鍵盤の外のゾーンは鍵盤の端に細く出すので、どのゾーンも押して選べる。
- Drum Kit: 左にバンク A–H と 4×4 のパッド、右に選んだパッドの名・Choke・Layer Mode・Trigger・レイヤーの帯・サンプルの段・Env・Filter・Amp。パッドの下の段にサンプルの名、レイヤーが 2 つ以上なら「Vel n」、M・S。バンクを押すと同じ位置のパッドへ移る（A2 → B2）。レイヤーの帯はベロシティの分け方を音と同じ計算で出し、押したレイヤーの波形を出す。1〜2 のベロシティしかないレイヤーも幅 14 を下回らない（広いレイヤーから分ける）。Velocity のときは、隣り合うレイヤーの間に境目（当たり 10、2×18 の線）があり、ドラッグで前のレイヤーの終わりを動かす（帯の幅で 128 段、Shift で 4 分の 1）。動かせるのは、そのレイヤーの最低から次のレイヤーの終わりの 1 つ下まで。離したときにパッドのすべてのレイヤーの `file<n>.top` を 1 回の変更で書く（上がる順になるようにし、音もこの順で分ける）。押した後の ← → は 4 ずつ、Shift で 1 ずつ動かし、1 回ずつ 1 段。掴んでいる間の Esc は何も入れない。
- ‹ › は `plugin.samples.step`、M・S は `plugin.param.set`（`A1.mute`）。どれも 1 回の変更で、元に戻す・やり直すも 1 回。
- 窓へファイルをドロップすると `plugin.samples.load --paths` で 1 回に読み込む。Drum Kit ではドロップしたパッド（パッドの外なら選んでいるパッド）から空いたパッドへ並べ、最初のファイルが入ったパッドを選ぶ（`Tom_v1`・`Tom_v2` は 1 つのパッドのレイヤーになる）。Shift を押しながら落とすと、すべてが 1 つのパッドのレイヤーになる（`--layers`）。音声でないファイルが混ざっていたら、それだけを飛ばして名前を知らせ、ほかは入れる（`plugin.samples.load` の `skipped`）。
- 窓は、どのコマンドの後・元に戻した後でも、ファイルの数に合わせて選んだゾーン・パッド・レイヤーを詰め直す。
- まだ作っていない部分（モックで形の決まっていない所と、ほかの項目を待つ所）: 狭い形、Output のメニュー、ドラッグ中の見積もりの重ね表示、サンプルの名のメニュー、パッドの右クリックのメニュー、再生位置とエンベロープの動く点、Drum Kit の全体の音量のつまみ。

## コマンド

| コマンド | すること |
|---|---|
| `plugin.samples.load` | ファイル、またはフォルダーの音声ファイル（名前順）を読み込む。`--path` は 1 つ、`--paths` はまとめて（画面へまとめてドロップしたもの）で、どちらも 1 回の変更になる。Drum Kit では空いたパッドへ並べ、`--dry-run` は埋まるパッドを返す（画面のドラッグ中の見積もり「21 パッド、A1–B5」）。 |
| `plugin.samples.add` | ファイルを足す（ディスクは読まない）。Drum Kit では名前の末尾の `_v<n>`（ベロシティ）・`_rr<n>`（ラウンドロビン）が同じファイルを 1 つのパッドのレイヤーにまとめ、`--layers` はすべてを 1 つのパッドのレイヤーにする。 |
| `plugin.samples.set` | 1 つのファイルを差し替える。値はそのまま。 |
| `plugin.samples.step` | 1 つのファイルを、同じフォルダーの前・後の音声ファイルに替える（端で一周する）。 |
| `plugin.samples.remove` | 1 つのファイル（`--index`）、1 つのパッドのファイル（`--pad`）、すべて（`--all`）を外す。 |
| `plugin.param.set` | `file2.start`・`A1.choke` のキーで値を変える。無いファイルのキーは断る。 |

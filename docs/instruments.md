# 組み込みの楽器

Sampler（PLG-067）と Drum Kit（PLG-068）の値と、曲の形式でのしまい方。ほかの組み込みの装置（EQ・Compressor ほか）と同じく、値は曲の中の `Plugin.params`（0..1 に正規化した値）に、読むファイルは `Plugin.samples` に入る。曲の形式の版は上げていない。

## 音の部品（両方で同じ）

Sampler と Drum Kit は同じ声（`crates/xirius-engine/src/stock/voice.rs`）で鳴る。声の値は次の 13 個。

| id | 名前 | 範囲 |
|---|---|---|
| `attack` `decay` `release` | エンベロープ | ms |
| `sustain` | エンベロープ | % |
| `ftype` | フィルターの型 | LP・BP・HP |
| `cutoff` `resonance` `drive` | フィルター | Hz・%・% |
| `transpose` `fine` | 音の高さ | 半音（±48）・セント（±100） |
| `volume` `pan` `velocity` | アンプ | dB・パン・ベロシティの効き % |

サンプルの鳴らし方は次の 8 個。開始・終わり・ループの位置はファイルの長さに対する割合。

| id | 名前 |
|---|---|
| `start` `end` | 鳴らす範囲 |
| `loop` `loop_start` `loop_end` `xfade` | ループと、その継ぎ目のクロスフェード |
| `reverse` `normalize` | 逆再生・ノーマライズ |

## Sampler

- 声の 13 個は楽器に 1 組（画面ではエンベロープ・フィルター・アンプを 1 回だけ出す）。キーは id のまま（`cutoff`）。
- サンプルの鳴らし方の 8 個はゾーン（ファイル）ごと。キーは `file<n>.<id>`（`n` は `samples` の 1 から数えた位置。例: `file2.loop_start`）。

## Drum Kit

- バンク A–H × 16 = 128 パッド（A1..H16）。パッド `i` はノート 36 + `i` で鳴る（127 を超えると 0 から数え直す。F13 = ノート 0）。
- 楽器に 1 つ: `volume`。
- パッドごと（キーは `<パッド>.<id>`。例: `A1.cutoff`、`B5.choke`）: 声の 13 個、サンプルの鳴らし方の 8 個、それに次の 5 個。
  - `layer_mode`: レイヤーの選び方（Velocity・Round Robin・Random・Stack）。
  - `trigger`: One Shot・Loop・Normal・Toggle。
  - `choke`: None・Self・1–32。
  - `mute`・`solo`。
- ファイルごと（キーは `file<n>.<id>`）: `pad`（そのファイルが鳴るパッド）と `top`（Velocity のときのレイヤーの上端、1–127）。
  - `file<n>.pad` が無いファイルは、`n` 番目のパッドで鳴る。ファイルを足す・外すコマンドは、どのファイルにも `pad` を書いてから並べ替えるので、ほかのファイルのパッドは動かない。
  - 1 つのパッドに載ったファイルがそのパッドのレイヤー。順はファイルの並び順。

## しまい方の決まり

- 値は既定と同じでも書いてよく、無いキーは既定の値になる。`plugin.param.list` は、ファイルごと・パッドごとのキーを書いてあるものだけ出す。
- ファイルを外すと、そのファイルの `file<n>.*` は消え、後ろのファイルの `file<n>.*` は 1 つずつ詰まる。ファイルの並びと値は 1 つの変更で動き、元に戻す・やり直すも 1 回で戻る。
- Drum Kit で、外したためにファイルが 1 つも無くなったパッドは、パッドの値（`A1.choke` ほか）も消える。後でそのパッドへ落とした音が、前の Choke・Trigger で鳴らないように。`--replace` は全部のパッドの値を消す。ただし新しいファイルが入るパッドの Mute・Solo は、ドロップで置き換えるときと同じく残す（入らずに空いたパッドのものは消える）。ファイルを持ったことの無いパッドに書いた値は残す。
- ファイルを足すとき、並びの後ろに残った `file<n>.*`（手で書いた曲のもの）は、新しいファイルの値にしない。
- 大文字・小文字や桁の違う書き方（手で書いた `FILE01.START`・`a1.choke`）は、曲を読むときに曲のキー（`file1.start`・`A1.choke`）へ直す。両方があれば曲のキーの値を残す。そのため、どの書き方でもゾーン・パッドに効き、`plugin.param.list` にも 1 行で出る。プリセット（デバイスのプリセット・トラックのプリセット）を入れるときも同じに直す。
- 曲を保存すると、`samples` のファイルはクリップの音と同じく曲のフォルダーに集まり、曲のフォルダーからの相対のパスになる（ENG-077）。
- プリセット（`.xpreset`）は `params` のすべてのキーと `samples` を持つ。読むと、つまみの値に加えて、ゾーンごと・パッドごとの値とサンプルも戻る。
  - サンプルは、プリセットのフォルダーの `samples/` に写して持つ。名前は `<元の名前>-<中身の sha256 の先頭 16 桁>.<拡張子>` で、プリセットには `preset:samples/<名前>`（プリセットのフォルダーからの相対）と書く。同じ音は 1 つの写しになり、同じ名前の違う音は別の写しになる。もう `samples/` の中にあるファイル（プリセットを読んだ曲が鳴らしている写し）は、そのままの名前で書くので、読んでは保存し直しても写しは増えない。写すファイルが `samples` という名のフォルダーの中（曲やプリセットの写し）なら、末尾の `-<16 桁>` をいくつでも落とした名前を元の名前にする。ほかの所のファイルは、名前の末尾がたまたま `-<16 桁>` でもそのまま元の名前にする。写しが無くなった後に探す名前は、写しの名前から末尾の `-<16 桁>` を 1 つだけ落とした名前。曲のフォルダーや人のフォルダーのパスは書かないので、サンプルを動かしても、プリセットのフォルダーを別の PC へ写しても鳴る。保存のときにディスクに無いサンプルは、ファイルの名前だけを書く。
  - 読むときは、書いた所（写し、曲のフォルダーからの相対）を見て、無ければ同じ名前のファイル（大文字・小文字は問わない）を、曲のフォルダー（4 段の下まで）、プリセットのファイルのあるフォルダー、プリセットの `samples/` の順に探す。見つかった所は曲のファイルと同じ書き方（曲のフォルダーの中なら相対）で入る。
    - 写しの名前には中身のハッシュがあるので、探して見つけたファイルは中身のハッシュが合うときだけ使う（同じ名前の違う音は使わない）。
    - 写しでない名前のうち、この PC のドライブの絶対のパス（`C:\…`。`..` と 2 つ目の `:` を含まないもの）は、その場所を開く（v1.1.0-beta.3 は曲の外のサンプルをこう書いた。次に保存すると `samples/` へ写す）。UNC（`\\…`、開くとサインインの情報を渡す）・`\\?\…`・`..`・`:` を含むものは、その場所を見に行かず、ファイルの名前だけで上の順に探す（よそから来たプリセットが曲のフォルダーの外を開かせない）。写しの名前も `:` を含めば使わない。
    - 探すときのファイルの一覧は、1 回の読み込みで 1 度だけ作る（全部で 20000 項目まで）。
    - 写しは消さない。プリセットを読んだ曲は写しをそのまま鳴らすので、どのプリセットも指さない写しでも、曲のサンプルであることがある。保存の下見（dry）はファイルを読まない。
  - どこにも無いサンプルは、そのファイルのゾーンの値（`file<n>.*`）と一緒に外し、後ろのファイルの値は詰める（ファイルを外すのと同じ）。外したことはファイルの名前で返す（「サンプルが見つからないため外しました」）。外すのはリストの位置で決める（保存していない曲で名前のまま残したサンプルが同じ名前でも、それは外さない）。Drum Kit では、残るファイルは今のパッドに留まる。
  - `samples` を持たない前の版のプリセットは、ファイルに触らない。ファイルとパッドの並び（`file<n>.*`）とパッドの値（`A1.choke` ほか）は今のまま残し、機器の値だけを入れる。
  - 画面（窓の一覧・‹ ›・ブラウザー）も CLI・MCP と同じ `preset.load` を通るので、どの道でも同じに戻る。値・サンプル・プリセットの名前が 1 つの変更で入り、元に戻すも 1 回。
  - `Default` は機器の出荷の形で、サンプルも空にする。
  - 保存していない曲で相対のパスのサンプルは、無いとは決められないので、探さずにそのまま入れる。
  - ブラウザーから、その機器の無いトラックへ読むと、機器を足すのとプリセットが 1 つの変更になる（`preset.load` の `device`）。トラックの無い所へ読むと、トラックを作る変更とプリセットの 2 つになる。

## 古い曲

- PLG-067・PLG-068 の前の曲は、そのまま開ける。開いただけでは変更あり（dirty）にならない。
- 前の Sampler の `sound`、前の Drum Kit の `kit`・`tune`・`decay`・`velocity`・`kick`・`snare`・`hats`・`toms`・`cymbals`・`percussion`（合成の音色の値）は、使わなくなったキー（`BuiltinDef::retired`）。曲には書いたまま残り、音にもエラーにも出ない。合成の音色はもう無いので、声の値は既定から始まる。
  - 前の Sampler の `tune`（±24 半音）はファイルの声にも効いていたので、読むときに同じ半音の `transpose`（±48）へ移す（`transpose` があればそちらを残す）。オートメーションの線とマクロの割り当ても `transpose` に向け、値と範囲を広い幅に直す（`transpose` の線や割り当てがあればそちらを残す）。手書きのキー（`CUTOFF` ほか）の値・線・割り当ても曲のキーへ移す。プリセットを入れるときも、機器・トラック・チェーン（FX チェーン・楽器と FX・マルチ）のどれでも同じ。前の Drum Kit の `tune` は合成のキットの値で、移さない。
  - プリセットに保存するときは、これらのキーを入れない（読み込むときも触らない）。

## サンプルが無い間

- サンプルが 1 つも無い Sampler・Drum Kit は、楽器の無いトラックと同じ仮の音（Sampler は音程のある音、Drum Kit は打つ音）で鳴る。「MIDI を演奏」や MIDI ファイルの読み込みで作ったトラックが、サンプルを入れる前から鳴るように。
- 最初のファイルが入ると楽器の音に替わり、すべてを外すと仮の音に戻る。仮の音は楽器の値（エンベロープ・フィルターほか）を使わない。

## 画面（UI-333・UI-334）

形は devices-v2 のモック（`docs/ui-approved.md` の「内蔵の機器の窓とプリセット」）。窓の中身は `crates/xirius-ui/src/device/sampler.rs`、窓の押す所は `crates/xirius-ui/src/instrument/spots.rs`。

- サンプルが 1 つも無い間は、つまみを出さず、ドロップの面（「Drop samples here」と「Browse」）だけを出す。Browse はブラウザーのファイルのタブを開く。最初のファイルが入ると窓が伸びて、サンプルの段と声のつまみが出る。
- Sampler: 上にサンプルの段（‹ 名前 ›、Loop・Reverse・Normalize、Loop が入っている間だけ Loop の後に小さい X-Fade のつまみ（大きさ 20、名前・つまみ・値の横並び）、波形と開始・終わりの点。Drum Kit も同じ）、その下に Env・Filter・Amp、鍵盤の上にゾーンの帯。ゾーンを押すとそのファイルを選び、サンプルの段とつまみはそのファイルの `file<n>.*` を指す。選んだゾーンは窓を開いている間だけ覚え、曲にも履歴にも入れない。根音が同じゾーン（名前に音名の無いファイルはどれも C3）は、その根音の受け持つ鍵を分ける。2 つなら根音までと根音の 1 つ上から（モックと同じ）、3 つ以上なら等しく分けて順に並べ、どれも鳴る（鍵が足りないときは、余った分が一番上の鍵を分け合う）。ゾーンは白鍵の列で置き、黒鍵で始まる・終わるゾーンは、その黒鍵の乗る線で区切るので、黒鍵で隣り合うゾーンも鍵の幅のまま並ぶ。鍵盤の外のゾーンは鍵盤の端に細く（6）出し、隣のゾーンはその後ろから始まる。右の端を越えるほど並んだときは、左へ詰め直して鍵盤の中に収める。ゾーンの間は 2 空け、右の端に届くゾーンは削らない。どのゾーンも押して選べる。根音の点はゾーンの中に収め、根音が鍵盤の外なら端に寄せる。
- Drum Kit: 左にバンク A–H と 4×4 のパッド、右に選んだパッドの名・Choke・Layer Mode・Trigger・レイヤーの帯・サンプルの段・Env・Filter・Amp。パッドの下の段にサンプルの名、レイヤーが 2 つ以上なら「Vel n」、M・S。バンクを押すとそのバンクのパッドを出し、選んだパッドは変えない（モックのとおり。そのバンクのパッドを押すと選ぶ）。サンプルの無いキットでも、押したパッドを選び、ファイルが来ても選んだパッドのまま。レイヤーの帯はベロシティの分け方を音と同じ計算で出し、押したレイヤーの波形を出す。1〜2 のベロシティしかないレイヤーも幅 14 を下回らない（広いレイヤーから分ける）。Velocity のときは、隣り合うレイヤーの間に境目（当たり 10、2×18 の線）があり、ドラッグで前のレイヤーの終わりを動かす（帯の幅で 128 段、Shift で 4 分の 1）。動かせるのは、そのレイヤーの最低から次のレイヤーの終わりの 1 つ下まで。離したときに、押したときに選んでいたパッドのすべてのレイヤーの `file<n>.top` を 1 回の変更で書く（上がる順になるようにし、音もこの順で分ける）。押した後の ← → は 4 ずつ、Shift で 1 ずつ動かし、1 回ずつ 1 段。掴んでいる間の Esc は何も入れない。
- ‹ › は `plugin.samples.step`、M・S は `plugin.param.set`（`A1.mute`）。どれも 1 回の変更で、元に戻す・やり直すも 1 回。
- 窓へファイルをドロップすると `plugin.samples.load --paths` で 1 回に読み込む。Drum Kit ではドロップしたパッド（パッドの外なら選んでいるパッド）から順にパッドへ並べ、そのパッドを選ぶ（`Tom_v1`・`Tom_v2` は 1 つのパッドのレイヤーになる）。モックの `fill` のとおり、並べる先にファイルのあるパッドがあれば、そのファイルとパッドの値を外して新しい音に置き換える（Mute・Solo は音の値ではないので残す）。H16 を越えた分は入れず、メッセージで「入りきらない n 個は入れていません」と知らせる（`plugin.samples.add` と `plugin.samples.load` の `left_out`、`plugin.samples.add` の `replaced`。N3-kit-2）。窓では、ドラッグ中のチップに「（n 個は入らない）」を足し、落とした後はレーンの下の知らせの行（エラーではない）に「パッドに入りきらない n 個は入れていません」と出す（N4-kit-1）。`--pad` を書かないコマンドは、前のとおり A1 から空いたパッドへ並べ、空きが尽きたら残りを入れない。Shift を押しながら落とすと、すべてが 1 つのパッドのレイヤーになる（`--layers`）。パッドの上に落としたときは、そのパッドにファイルがあっても、そのパッドのレイヤーに足す（`--pad` と `--layers`。どう選ぶか（Layer Mode）は前のまま）。音声でないファイルが混ざっていたら、それだけを飛ばして名前を知らせ、ほかは入れる（`plugin.samples.load` の `skipped`）。
- 窓は、どのコマンドの後・元に戻した後でも、ファイルの数に合わせて選んだゾーン・パッド・レイヤーを詰め直す。
- メニュー（モックのとおり。どの行もコマンドを通し、通らないときは選べない）:
  - サンプルの名（押す・右クリック）: 「サンプルを置き換え…」「ブラウザーで表示」、区切り、Sampler は「このゾーンを外す」「すべてのサンプルを外す」、Drum Kit は「このレイヤーを外す」（パッドにほかのレイヤーがあるときだけ）。
  - 置き換えは OS のファイルの窓で選び、`plugin.samples.load --index` で 1 回に入れる。曲の中の場所の書き方（曲のフォルダーの中なら相対）は読み込みと同じで、そのサンプルの値（`file<n>.*`）はそのまま残る。
  - 「ブラウザーで表示」は、ブラウザーのファイルのタブ（曲のフォルダー・足した場所）のどれかがそのファイルのフォルダーを含むときだけ選べる。そのタブを開き、フォルダーを開いて、ファイルを選んで見える所まで送る（鳴らさない）。
  - ゾーンの右クリック: そのゾーンを選び、「このゾーンを外す」。
  - レイヤーの右クリック: 選ばずに「このレイヤーを外す」（パッドにほかのレイヤーがあるときだけ）。
  - パッドの右クリック: そのパッドを選び、「サンプルを置き換え…」（空のパッドでは選べない。今の 1 つ目のレイヤーを置き換える）「サンプルを足す…」（OS の窓で複数を選び、そのパッドのレイヤーに足す）、区切り、「パッドを空にする」（空なら選べない）「バンクを空にする」（どのパッドも空なら選べない。`plugin.samples.remove --pad` と `--bank`）。
  - フィルターの点の右クリック: LP・BP・HP（今の型に印）、区切り、「フィルターを開く（かけない）」（LP・カットオフ 20 kHz・レゾナンス 0）。これが既定と同じなので、「既定に戻す」は重ねて出さない。
- パッドとバンクの状態（モックのとおり）:
  - パッドの面: ファイルのあるパッドは s3（ホバーで clip）、空のパッドは s2（ホバーで s3）。選んでいるパッドは内側に 2 px の ink-blue の線。
  - 鳴らないパッド（M が入っている、またはほかのパッドに S が入っていて自分に無い）は、パッドの名とサンプルの名を薄く出す（モックは 0.45 の不透明度。字の色に不透明度を掛けない決まりのため、使えないタブの字と同じ不透明な色にする）。
  - 押したパッドは押している間と、短く押しても 120 ms は fill（字は on-fill）で光る。ベロシティは押した高さで決める（上端 127、下端 1。`round((1 - y/h) × 126) + 1`）。Sampler の鍵盤は今までどおり一定。
  - M・S: 切れているときは面なし（ホバーで s1）、入っているときは M がミキサーの Mute、S が Solo と同じ色。
  - バンク: 面なし、ホバーと選んでいるバンクは s3、選んでいるバンクの字は ink-strong。サンプルのあるバンクは字の下（下から 3 px）に 4 px の ink-blue の点。
- Sampler の鍵盤を押すと、その音を鳴らすゾーンを選ぶ（波形とその値がそのゾーンに替わる）。
- ドラッグ中の見込み（Drum Kit）: ファイルを窓の上へドラッグしている間、落としたときに入るパッドを先に見せる。数え方は `plugin.samples.load` と同じ（`kit_groups` と `kit_pads`）で、音声でないファイルは数えない。
  - 入るパッドは s1 の面に 2 px の focus の線、字は ink-blue で、入る名とレイヤーの数（`Vel 2`）を出し、M・S は隠す。ファイルのあるパッドへ Shift で足すときは、そのパッドの名と、足した後のレイヤーの数を出す。そのパッドを含むバンクの字も ink-blue。
  - ポインターの右下（+14, +10）に、高さ 24 の s1 の札で「2 pads, A1–A2」「A1: 3 layers」「A1: Kick」を ink-blue で出す。
  - フォルダーは、ドラッグ 1 回につき 1 度だけ、落としたときと同じ関数（`audio_files`、名前順）で中の音を読み、ファイルと同じに数える（「21 pads, A1–B5」、バンクの点も付く。N3-kit-1）。
  - レイヤーの帯の上では、選んでいるパッドのレイヤーに足す見込みを出す。レイヤーとして足すとき（Shift・帯）の札は、足した後のそのパッドのレイヤーの数（「A1: 3 layers」。1 つになるときは名）。
  - ポインターを動かさずに Shift を押す・離すだけでも、最後の位置で見込みを計算し直す。
  - 並べる先のファイルのあるパッドは、置き換わった後の名を見せる。H16 を越えた分は数えない（札の数が落とすファイルの数より少なくなる。札の文はモックのまま）。
  - 窓の外、ドラッグが窓を出たとき、落としたときは消す。
- 鳴っている声の位置（モックのとおり）: 窓が開いている間、Sampler と Drum Kit のいちばん新しい声を probe から読み、波形とエンベロープに出す。バイパス中と、声が消えたら（フェード中も）出さない。
  - 波形: 声が読んでいる所に 2 px の ink-strong の縦線。波形が見せているファイルを鳴らしているときだけで（Sampler はほかのゾーン、Drum Kit はほかのレイヤーなら出さない）、Start と End の間にいるときだけ。Reverse のときは、モックと同じく Start から End へ進むように見せる（エンジンは切り取った所を End から Start へ読む）。波形は Start と End の間だけをその場で裏返して描き（外はそのまま）、線はその裏返した波形の、声が読んでいる所に立つ。ループの範囲と両端の印も、裏返した波形の上でファイルのループがある所に出す（声はその中で回る）。そのとき画面で左の印を Loop Start、右を Loop End とし、ツールチップ・読み上げ・ホイール・キー・入力の値は画面の位置のもの（Start + End からファイルの値を引いたもの）にする。切り取りの外にあるループの端は、声と同じく切り取りの端に寄せてから裏返すので、印は波形の上の鳴る所に出て、そこで掴め、読み上げもその所の値を言う。左の印が動かすのはファイルの Loop End で、引けば印はポインターについて行き、右へ引くほど値が増える（向きは変わらず、切り取りの端で止まる）。裏返る途中も、印は元の所から鳴る所へまっすぐ動き、波形の外へ出ない。Reverse を押すと、Start と End の間の波形・ループの範囲・両端の印・線は 240 ms でその場で裏返り（動きを減らす設定では一度に変わる）、Start と End の印と外の暗い所は動かない。モックは波形をまるごと裏返すが、Start と End の外を裏返さないために、この形にしている。
  - エンベロープ: 半径 4 の ink-strong の点。Attack は高さ（レベル）で上り、Decay と Release はその段に入ってからの時間で進み、Decay を過ぎて Sustain にいる間は、Sustain の区間をゆっくり（0.8 秒の時定数で）右へ進む。Release が終われば消す。Drum Kit は選んでいるパッドの声のときだけ。
  - 段に入った時刻は、窓の側で、音の高さ・ファイル・段が変わったときに取り直す。
- ゾーン・レイヤー・バンク・パッドの題（モックのとおり）:
  - ゾーンの帯とレイヤーの帯は s2 の地（角は Clip）。ゾーンとレイヤーの面は s3、ホバーで clip、選んでいるものは fill。ゾーンの帯の高さは 22、レイヤーの帯とバンクは 24。ゾーンの根音の点は 5 px。ゾーンとレイヤーの字は fs-micro の regular。ゾーンは鍵より 2 px 短く、字は左右 4 px 内側。
  - レイヤーの字: Velocity でレイヤーが 2 つ以上なら、そのベロシティの範囲（`1–63`）。ほかは番号。Layer Mode の札は Vel・RR・Rnd・Stack。
  - 選んだパッドの題: パッドの名（Small Semibold）、その横にサンプルの名（Small、入るだけ）、音名（Caption）。
  - ファイルのある Drum Kit で空のパッドを選んだときは、題とドロップの面だけを出す（Choke・Layer Mode・レイヤー・声のつまみは出さない）。
- 波形の色（モックのとおり）: 地は s2、波形は thumb-hover（インクに不透明度をかけない。バイパス中も同じで、モックがバイパスで色を変えるのはグラフの線だけ）、ループの範囲は s3（角 Clip、上下 2 px 内側）、Start より前と End より後は s0 の 0.72 を重ねる。
- 波形の印（モックのとおり）: Start・End は波形の高さいっぱいの 3 px の棒と、上端の 12×10 のつまみ。ループの両端はつまみが下端にあり、ink-blue。掴んでいる・ホバーしているものは ink-strong。バイパス中も同じ色（モックがバイパスで薄くするのはグラフの線だけで、印は波形に埋もれないようにする）。選んでフォーカスがあるときの棒は focus の色。
- ファイルを落とす先（モックのとおり）: ドラッグ中、落とす先を先に見せる。空の窓のドロップの面は s3 の面と ink-blue の印。ほかは落とす先を 2 px の focus の線で囲む。
  - Sampler: ゾーンの帯の上なら、ゾーンを足す。波形やほかの所なら、今のサンプルを外して、落としたファイルに置き換える（`--replace`。1 回の変更）。
  - Drum Kit: レイヤーの帯の上なら、選んでいるパッドのレイヤーに足す（Shift と同じ）。パッドの上はそのパッド、ほかの所は今までどおり。
- 鳴ったレイヤーを選ぶ（モックのとおり）: 窓のパッドを押すと、そのパッドで鳴った声のレイヤーを選ぶ（RR・Rnd・Velocity で鳴ったもの）。Stack は全部が鳴るので、選んでいるレイヤーを替えない。押してから 500 ms のうちに届いた声だけを見て、1 回で終える。
- UIA: パッドは「A1 C1, Kick」（名・音名・サンプルの名）の Button で、選んでいるパッドは selected。選んだパッドの題は「A1, Kick, C1」の Label。ゾーンは「Piano_C3, root C3」、レイヤーは「Layer 1」「Layer 0–63」の Button。レイヤーの辺は「Layer 1 top」の Slider で、値はそのレイヤーの上の端の velocity（動かせる範囲と幅 1 を持つ）。増減は 1 つずつ、値を入れるとその velocity へ、どちらも 1 手で動く（矢印のキーと同じ `layer_edge_set` を通る）。
- 狭い形（モックのとおり）: Sampler は 780、Drum Kit は 905 で開き、どちらも 520 まで狭められる。幅の決まりは、窓の中身の幅（両側の余白を除いた幅）で見る。
  - Env・Filter・Amp: 3 つが並ばない幅（260 + 200 + Amp + 間）では、Amp が Env と Filter の下へ回り、Env と Filter は 260 と 200 から 3 : 2 で幅を分ける。620 以下では、Amp が幅いっぱいになり、つまみを 1 列に並べる。
  - サンプルの行: 名前が 80 より狭くなるときは、Loop・Reverse・Normalize（と X-Fade）を次の行へ回す。
  - 鍵盤: 520 以下では C の名前を出さない。
  - Drum Kit: 700 以下では、バンクとパッドを上に、最大 340 の幅で真ん中に置き、選んだパッドの編集をその下に置く。パッドの高さは幅の 0.86。波形は 96、空のときの落とす面は 196 の高さで、窓を高くした分は波形（または落とす面）が受け取り、パッドは伸ばさない。
- まだ作っていない部分（モックで形の決まっていない所と、ほかの項目を待つ所）: Output のメニュー、Drum Kit の全体の音量のつまみ。

## コマンド

| コマンド | すること |
|---|---|
| `plugin.samples.load` | ファイル、またはフォルダーの音声ファイル（名前順）を読み込む。`--path` は 1 つ、`--paths` はまとめて（画面へまとめてドロップしたもの）で、どちらも 1 回の変更になる。Drum Kit では `--pad` から順に並べ（ファイルのあるパッドは置き換え、H16 を越えた分は入れない。`--pad` が無ければ A1 から空いたパッドへ）、`--dry-run` は埋まるパッドを返す（画面のドラッグ中の見積もり「21 パッド、A1–B5」）。 |
| `plugin.samples.add` | ファイルを足す（ディスクは読まない）。Drum Kit では名前の末尾の `_v<n>`（ベロシティ）・`_rr<n>`（ラウンドロビン）が同じファイルを 1 つのパッドのレイヤーにまとめ、`--layers` はすべてを 1 つのパッドのレイヤーにする。 |
| `plugin.samples.set` | 1 つのファイルを差し替える。値はそのまま。 |
| `plugin.samples.step` | 1 つのファイルを、同じフォルダーの前・後の音声ファイルに替える（端で一周する）。 |
| `plugin.samples.remove` | 1 つのファイル（`--index`）、1 つのパッドのファイル（`--pad`）、すべて（`--all`）を外す。 |
| `plugin.param.set` | `file2.start`・`A1.choke` のキーで値を変える。無いファイルのキーは断る。 |

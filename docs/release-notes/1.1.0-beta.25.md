# Xirius 1.1.0-beta.25

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 1.1.0-beta.24 で、外部のプラグインの窓が開かない・開くのにとても時間がかかる・窓の上の帯のボタンが効かないことがあったのを直しました
- プラグインを押すと、すぐに窓が出るようになりました。開くまで時間がかかるときは、窓の中に回る印が出ます。× を押すと、開くのを取り消せます
- プラグインの窓は、前に開いたときの大きさで出るようになりました（Xirius を閉じるまで覚えます）
- 開くのに時間がかかるプラグインの窓が、開いた直後に閉じられることがあったのを直しました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

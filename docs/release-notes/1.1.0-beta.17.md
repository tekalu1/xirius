# Xirius 1.1.0-beta.17

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 左のブラウザーのサンプルを、Drum Kit と Sampler の窓へドラッグして入れられるようになりました。入るパッドは、落とす前に枠と名前で分かります
- 「Drop samples here」の面は、選んでいるパッドに入るときだけ光るようになりました
- Drum Kit の Browse で選んだファイルも、名前の末尾が _v1・_v2… や _rr1・_rr2… の物は、1 つのパッドのレイヤーにまとまるようになりました
- Drum Kit と Sampler の窓に落としたときの知らせが、その窓に出るようになりました
- ブラウザーのサンプルを機器の窓の上で離すと、裏のタイムラインに置かれていたのを直しました
- 操作のパレットと右クリックのメニューが、速く開くようになりました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

# Xirius 1.1.0-beta.44

This beta is for Windows 10 and 11 (x64). To receive beta updates in the app, turn on **Receive beta versions** in Settings.

## Changed

- The marks at a clip's top right, such as the loop mark, now sit a little further left, so the fade handle that a selected audio clip shows at its top-right corner no longer covers them. They stay in the same place whether the clip is selected or not.

## Fixed

- Loading a preset on a built-in instrument or effect could leave some of its knobs, such as a filter's cutoff or the Sampler's tune, at their old values until the song was opened again. The preset's values now take effect at once.
- Deleting clips together with selected automation points, or notes together with controller points, made two undo steps, so one Undo brought back only part of what was deleted. Each is now one undo step.

## Known issues

- When you drag a file from File Explorer over a place that doesn't take files, the pointer still shows the copy sign. Nothing is placed if you let go there.
- Xirius may continue using CPU while the confirmation for closing a song or quitting is open. This is under investigation.

If the in-app update from 1.1.0-beta.2 or 1.1.0-beta.3 fails, close Xirius and use the installer on this page.

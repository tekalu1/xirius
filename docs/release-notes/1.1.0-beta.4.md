# Xirius 1.1.0-beta.4

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- Sampler の窓に、ゾーンと波形の画面を足しました。サンプルを鍵盤の範囲ごとに割り当て、Start・End・ループ・Reverse を波形の上で決められます
- Drum Kit の窓に、バンクとレイヤーの画面を足しました。パッドごとにサンプルを重ね、境目を引いて分けられます
- 機器の窓を狭めたときの形と、右クリックのメニューを足しました
- チャンネルエディターのプリセットの一覧の先頭に「Default」を置き、新しいトラックは Default から始まります。手で組み替えたときは名前の代わりに「—」と点を出します
- スプリッターの分岐の先頭にエフェクトを足す「＋」を、分岐の頭の下に移しました
- アプリの中の更新で、「更新」を押すと Xirius が閉じたまま新しい版が入らないことがあったのを直しました
- 窓を閉じるときに Xirius が落ちることがあったのを直しました
- Sampler・Drum Kit のプリセットを読み込んで保存し直しても、サンプルのファイルが増えないようにしました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。マクロの動く範囲と向きを変える画面は、まだ入っていません。

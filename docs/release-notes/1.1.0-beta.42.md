# Xirius 1.1.0-beta.42

This beta is for Windows 10 and 11 (x64). To receive beta updates in the app, turn on **Receive beta versions** in Settings.

## New

- Everything you can click now shows the pointing hand: the buttons on the top and bottom bars, the mute, solo, record-arm, monitor, color and fold buttons in the track list, the waveform zoom, automation lanes, the piano roll's buttons, the recording panel, notices, the start screen and the cards that appear while a song gets ready or comes back after a crash. The command palette's rows show the hand and its search box the text cursor.
- The floating instrument, channel and macro windows and the device windows now show cursors too: the hand on buttons, the up-down arrow on knobs and sliders, the arrow on the window's bar and the diagonal arrow at the resize corner.

## Changed

- The cursors Xirius draws itself (the open and closed hand and others) are now the same size as the Windows cursors at every display scale.
- The middle of a clip or a note shows the arrow, also while you drag it. The edges still show the left-right arrow; loops, sections, automation points and crossfades keep the hand.
- Knobs and faders keep the up-down arrow while you turn them.

## Known issues

- When you drag a file from File Explorer over a place that doesn't take files, the pointer still shows the copy sign. Nothing is placed if you let go there.
- Xirius may continue using CPU while the confirmation for closing a song or quitting is open. This is under investigation.

If the in-app update from 1.1.0-beta.2 or 1.1.0-beta.3 fails, close Xirius and use the installer on this page.

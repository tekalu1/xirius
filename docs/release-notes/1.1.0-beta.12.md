# Xirius 1.1.0-beta.12

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 機器の画面が、それぞれ独立した窓で開くようになりました。内蔵の機器もプラグインも同じ窓で、プリセットの帯・検索・保存の形がそろいます。窓の位置は覚えていて、別の機器を開いても開いたままにできるピン留めもできます
- 開いている機器の窓に、PC のキー・パッド・外部 MIDI の入力が正しく届くようになりました
- ブラウザーのお気に入りを、どの場所から付けても同じ一覧にそろえました。幅の狭いときも場所のタブが読めます
- ドラムキットやプラグインの入れ替えが失敗したとき、それまで採用されていた音がそのまま鳴り続けるようにしました。失敗している間も、音を止める操作（キーを離す・パニックなど）は届きます
- プラグインの状態を保存できなかったとき、保存できなかった理由を知らせるようにしました。その知らせは、保存が全部終わるまで消えません
- MP3 の書き出しで、使えるエンコーダーが無いときは失敗の理由を伝えるようにしました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

# Xirius 1.1.0-beta.41

This beta is for Windows 10 and 11 (x64). To receive beta updates in the app, turn on **Receive beta versions** in Settings.

## New

- While you drag an audio file from the browser or from File Explorer, the arrange view shows a see-through clip where it will land, with its name, waveform and length, and a line with the bar, beat and tick on the ruler. The start snaps to the grid; hold Shift to place it freely.
- Between tracks, the rows below move apart to show the new audio track the file will get. Over an instrument track, the file goes onto a new track just below it. The ruler, the section and tempo rows and the area outside the tracks don't take files.
- Several files are stacked on new tracks; hold Alt to place them one after another on a single track.
- The title bar of an ARA editor window now shows only the clip's track and the plugin's name, a pin and a close button. An unpinned ARA window gives way when another plugin's ARA window opens; a pinned one stays.

## Changed

- Press Esc, or click the empty area below the last track, to clear the clip selection. Esc first cancels a drag, a selection box or an open menu.

## Known issues

- When you drag a file from File Explorer over a place that doesn't take files, the pointer still shows the copy sign. Nothing is placed if you let go there.
- Xirius may continue using CPU while the confirmation for closing a song or quitting is open. This is under investigation.

If the in-app update from 1.1.0-beta.2 or 1.1.0-beta.3 fails, close Xirius and use the installer on this page.

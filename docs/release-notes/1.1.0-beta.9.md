# Xirius 1.1.0-beta.9

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 入力の無い音源のプラグイン（iZotope Iris 2 など）を差すと、Xirius ごと落ちることがあったのを直しました
- Xirius を落としたプラグインは、次に起動したときから別のプロセスで動かすようにしました。そのときは知らせを出し、「元に戻す」で元のとおりに戻せます
- プラグインごとの「別のプロセスで動かす」設定が、差した瞬間・曲を開いたとき・プリセットから差したときから効くようにしました
- 別のプロセスで動かす設定なのに、その仕組みを起動できないときは、Xirius の中で黙って動かさず、読み込みを止めて知らせるようにしました
- ミュートした分岐は、線が開いたスイッチの形で示すようにしました。分岐ごとに線を引き、空の分岐にも名前を出します
- インストゥルメントのアイコンを、鍵盤の形にしました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

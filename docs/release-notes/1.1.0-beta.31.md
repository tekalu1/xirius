# Xirius 1.1.0-beta.31

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- フォルダーの行が専用バスを兼ねるように変えました。フォルダーを閉じていても、同じ行でミュート（M）・ソロ（S）・音量・出力を操作でき、インサートを開けます
- 入れ子の専用バスは、出力が「既定」のとき、上の階層で最も近いフォルダーのバスへ送ります。上の階層にバスがなければマスターへ送ります
- フォルダーと拡張したトラックの出力欄は、ふだん背景の面を表示せず、カーソルを乗せたときと出力一覧を開いているときに表示するように変えました
- 今までの曲を開くと、フォルダー用に自動で作られ、今もそのフォルダーに接続され、ほかのフォルダーと共有されていない同名のバスは、フォルダーの行にまとまります。出力先やバスの設定は引き継ぎます。整理だけのフォルダー、複数のフォルダーで共有しているバス、名前を変えてフォルダーと名前が異なるバスはそのままです
- 開いたときの移行では、保存済みの曲の内容を書き換えません。この版で新しい形式に保存した曲は前の版で開けません
- フォルダーバスの移行・複製・出力経路を確かめる試験を加え、フォルダーの表示を確かめる試験を新しい行に合わせて変えました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

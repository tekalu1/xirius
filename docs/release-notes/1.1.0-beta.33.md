# Xirius 1.1.0-beta.33

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- これまでの版では、ARA プラグインで音程などを編集しても曲に保存されず、開き直すと編集が消えることがありました。新しい曲の最初の保存でも起きていました。最初の保存から ARA の編集を曲に含めるように変えました
- チャンネルや内蔵楽器の窓を押すと、その窓が外部プラグインの窓より手前に来るように変えました。外部の窓はメインの窓より手前に並び、外部の窓のうち最後に触ったものが一番手前に来ます（Windows）
- ブラウザーから楽器をドラッグしてトラックを作ると、楽器の窓も開くように変えました。トラック同士の境目や一覧の両端に楽器やエフェクトを落とすと、その位置にトラックができます。エフェクトの場合はオーディオトラックを作り、最初のインサートに入れます。外部プラグインの窓を表示する変更は Windows のみです
- 外部プラグインの帯からチャンネルの窓を開くと、収まる位置を探してプラグインの隣に置き、キー入力先をチャンネルの窓に移すように変えました。すでに開いている場合は、その位置で手前に出します（Windows）
- チャンネルのインサート一覧で Esc を押したとき、検索欄に文字があれば消去し、空なら一覧を閉じるように変えました
- プリセットを送れない方向の ‹ › と、VST3 のプリセット一覧の「ブラウザーに表示」を暗くして選べないように変えました。「ブラウザーに表示」の変更は Windows の外部 VST3 プラグインが対象です
- トラックの境目に外部エフェクトを落としてからその窓で編集せずに閉じた場合、取り消し 1 回で追加したトラックごと戻せるように変えました（Windows）
- 画面読み上げでトラックの一覧を読むと操作が止まる問題に対応し、一覧を読み取れるように変えました（Windows）
- CLI・MCP で楽器付きトラックを追加するとき、既存のトラックの直前を指定できるように変えました。トラックプリセットから作るときは、フォルダー内の位置も指定できます。エフェクト付きのオーディオトラックを位置指定で作るコマンド、`track.add.with-effect` を追加しました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

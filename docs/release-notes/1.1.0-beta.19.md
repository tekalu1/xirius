# Xirius 1.1.0-beta.19

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 内蔵のエフェクト「Pitch Correction」を足しました。歌などの音の高さを、選んだ Key と Scale の音へ、その場で寄せます
- Pitch Correction の鍵盤で、寄せる先の音を 1 つずつ入り切りできます。寄せる速さ（Speed）、音が移るときの速さ（Note Transition）、直す量（Amount）、声の響きを保つ Formant、探す高さの幅（Range）を選べます
- Pitch Correction の窓に、入力の高さと補正後の高さが線で出ます
- エフェクトへノートを送れるようになりました。Pitch Correction の窓のタイトルバーで、インストゥルメントのトラックを「ノートの送り元」に選ぶと、そのトラックのノートの音へ寄せます。つないだ先は、ミキサーとチャンネルエディターに印で出ます
- Pitch Correction の Key・Speed・Amount などを、オートメーションで動かせます

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

# Xirius 1.1.0-beta.36

This beta is for Windows 10 and 11 (x64). To receive beta updates in the app, turn on **Receive beta versions** in Settings.

## Changed

- Changed the recording-save regression test to wait until the audio engine has processed a recording block before stopping the recording.

## Device windows

These changes first shipped in beta.34. The window placement and replacement were verified by hand on Windows. macOS validation was limited to CI.

- Removed the instrument color squares. Selecting a layer highlights its card, range, and keys together.
- One unpinned instrument window and one unpinned FX window can stay open together. Opening another window of the same kind replaces the unpinned window. Pinned windows stay open. Selecting an open device brings its window forward.
- Fixed device window placement so windows use available space on the same screen. When windows must overlap, placement tries to keep title bars and close buttons accessible. Reopening or replacing a window keeps its previous position when there is room.

## Known issues

- When you reopen a song, an ARA clip can keep showing a loading indicator at 0% until you click the clip.
- If an ARA editor goes behind another app, Xirius may be unable to bring it back to the front.
- Editing or removing ARA may leave the song marked as saved even when it has unsaved changes.

If the in-app update from 1.1.0-beta.2 or 1.1.0-beta.3 fails, close Xirius and use the installer on this page.

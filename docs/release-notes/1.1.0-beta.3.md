# Xirius 1.1.0-beta.3

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 起動するとスタート画面を開きます。Ctrl+W・Ctrl+F4 で曲を閉じて、スタート画面に戻ります
- 内蔵の機器（EQ・Compressor・Limiter・Delay・Reverb・Sampler・Drum Kit）の窓を新しくしました。グラフの点を引いて値を変えられ、ピン留めした窓は並べて開いておけます
- 機器ごとにプリセットを保存・読み込みでき、ブラウザーからも選べます
- チャンネルエディターで、インサート・スプリッターの分岐・マルチインストゥルメントの層（鍵域とベロシティ）を組めます。組んだチェーンはプリセットとして保存できます
- マクロコントロール（Macro 1〜8 と X/Y パッド）で、複数の値をまとめて動かせます。割り当ては部品やつまみの右クリックから行い、オートメーションも書けます
- ミキサーのストリップにインストゥルメントとインサートを並べ、選んだ機器をストリップの右に広げて操作できます
- サイドチェーンの送り元を、受ける機器の窓のタイトルバーで選べます。スプリッターの分岐の中の機器にも届き、ミキサーには送り元と受ける側の印と GR を出します
- ARA に対応したプラグインを、オーディオクリップの右クリックの「ARA プラグインを追加…」から使えます。プラグインが落ちたときは、クリップの印のメニューから開き直せます
- アプリのアイコンを、枠いっぱいの形にしました

Sampler のゾーンと波形の画面、Drum Kit のバンクとレイヤーの画面、マクロの動く範囲と向きを変える画面は、まだ入っていません。試聴の待機アニメーションと読み上げ、環境によってクリップのトランスポーズがホイールで変わらない症状は、確認を続けています。

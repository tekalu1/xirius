# Xirius 1.1.0-beta.40

This beta is for Windows 10 and 11 (x64). To receive beta updates in the app, turn on **Receive beta versions** in Settings.

## Fixed

- Double-clicking a MIDI clip now opens the piano roll when the track's automation lanes are shown, and when you click just above or below the clip. Before, it added an overlapping empty part that appeared as take 2.
- Double-clicking an empty spot on an instrument track no longer adds a part over a time that a clip already covers.

## Known issues

- Xirius may continue using CPU while the confirmation for closing a song or quitting is open. This is under investigation.

If the in-app update from 1.1.0-beta.2 or 1.1.0-beta.3 fails, close Xirius and use the installer on this page.

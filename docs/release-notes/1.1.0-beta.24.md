# Xirius 1.1.0-beta.24

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 外部のプラグイン（VST3・CLAP・ARA）は、すべて Xirius とは別のプロセスで動くようになりました。プラグインが落ちても、Xirius は落ちずに音が続きます
- 同じメーカーのプラグインは、1 つのプロセスにまとめて動かします。右クリックの「動かす場所」で「専用」を選ぶと、そのプラグインだけを別のプロセスで動かせます。前の版で選んでいた「アプリの中」などの設定は、既定として読み替えます
- プラグインのプロセスが落ちたときは、最後の状態で自動で起こし直します。1 分に 3 回落ちたときは、手で起こし直すまで待ちます
- 別のプロセスでプラグインを動かすときに足していた遅れを無くしました
- 再生位置を動かした直後に、プラグインのオートメーションの値が古い値で上書きされることがあったのを直しました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

# Xirius 1.1.0-beta.7

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 起動したときに、スタート画面に「音を準備しています」が出たまま消えなかったのを直しました
- 曲を閉じてスタート画面に戻ったときに、準備中の表示が出ないようにしました
- オーディオデバイスを開けなかったときは、そのことを知らせるようにしました。鍵盤を弾いたときも知らせます
- スタート画面と新しい曲の画面で、誤りの知らせが右にずれて一覧に重なっていたのを直しました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

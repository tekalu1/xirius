# Xirius 1.1.0-beta.20

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- Drum Kit のパッドごとに、出力先（Output）を選べるようになりました。パッドの設定の Output で、Main・今あるバス・New Bus から選びます
- New Bus を選ぶと、パッドの音の名前のバスが、キットのすぐ下にできます
- バスへ出したパッドの音は、キットのトラックのインサートとフェーダーを通らず、そのバスへ直に入ります。キットのトラックのミュートとソロは、バスへ出したパッドにも効きます
- バスへ出したパッドには、名前の右に印が付きます。パッドを複数選んでいれば、Output をまとめて変えられます
- バスへ出したパッドがあるキットをバウンスすると、Main の分と、行き先のバスごとの分のオーディオのトラックができます。フリーズは、いまはできません

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

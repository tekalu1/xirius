# Xirius 1.1.0-beta.10

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- VST3 のプラグインの窓も、内蔵の機器と同じタイトルバーと枠で開くようにしました
- 内蔵の機器とチャンネルエディターの画面を、タイトルバーの「表示先」から独立したウィンドウへ出せるようにしました。同じ所から戻せます
- プラグインの窓が、Xirius の窓の後ろに回ってしまうのを直しました
- プラグインの窓を、Xirius のある画面の中に開き、前回の位置を覚えるようにしました
- ドラムキットと Sampler にサンプルを入れられなかったのを直しました
- パレットからオーディオを取り込むと断られていたのを直しました。クリップの反転・ノーマライズ・テンポの検出も同じく直しました
- 空のインストゥルメントと空のドラムキットは、音を鳴らさないようにしました
- ブラウザーの試聴の行を 1 つの面にまとめました。長いファイル名は末尾を省き、指したときに全文を出します
- ARA のプラグインに、途中で変わるテンポと拍子を渡すようにしました
- ループしたクリップも、ARA のプラグインで編集した音で鳴るようにしました
- ARA の解析の結果を曲と一緒に保存し、開き直すたびに解析し直さないようにしました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

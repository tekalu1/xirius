# Xirius 1.1.0-beta.13

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- Channel Editor と Macro Controls が、画面の中ではなく独立した窓で開くようになりました。画面の中に開く表示は無くなり、窓はメインウィンドウの前に出ます
- 内蔵の機器などの独立した窓を、タイトルバーの空いている所をつかんで動かせなかったのを直しました
- 独立した窓が、決めた位置と大きさで開くようになりました。閉じて開き直すと、前の位置と大きさに戻ります（アプリを開いている間）
- Multi Instrument の鍵盤を 1 段にしました。音域の図のすぐ下の鍵盤を押して、音を鳴らせます
- 右クリックのメニューで、行の少ないものは分類に分けず、そのまま並べるようにしました（例: Drum Kit のパッド）
- 右クリックのメニューの子のメニューが横に開いているときは、「戻る」の行を出さないようにしました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

# Xirius 1.1.0-beta.46

This beta is for Windows 10 and 11 (x64). To receive beta updates in the app, turn on **Receive beta versions** in Settings.

## Fixed

- With the audio driver set to WASAPI (exclusive), previewing sound files in the browser one after another could cut off the first moment of the new preview. That preview then never reached its end, and about 10 seconds later it reported that the song's audio output had stopped. Now every preview plays from its start to its end.

## Known issues

- When you drag a file from File Explorer over a place that doesn't take files, the pointer still shows the copy sign. Nothing is placed if you let go there.
- Xirius may continue using CPU while the confirmation for closing a song or quitting is open. This is under investigation.

If the in-app update from 1.1.0-beta.2 or 1.1.0-beta.3 fails, close Xirius and use the installer on this page.

# Xirius 1.1.0-beta.34

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- マルチインストゥルメントでは、楽器ごとの色の四角を外し、レイヤーの選択色をトラックの色に揃えました。選んだ楽器のカード・範囲の帯・鍵盤を一緒に強調するように変えました
- ピンで留めていない楽器とエフェクトの窓を、それぞれ一つずつ同時に開けるように変えました。同じ種類の窓を開くと前の窓と入れ替わり、ピンで留めた窓は残ります。すでに開いている楽器やエフェクトを選び直すと、その窓が手前に来るように変えました。楽器を足しても、開いている外部エフェクトの窓を保つように変えました。外部プラグインの窓の変更は Windows のみです
- 楽器やエフェクトの窓を新しく開くと、同じ画面内の空いている所を探すように変えました。閉じた窓を開き直すと、空いていれば前の位置に戻ります。重ねて置く場合は題名の帯と × が見える位置を探し、両方を残せる場所がないときは × を優先するように変えました。外部プラグインの窓と、内蔵の窓の外枠の位置を保存する変更は Windows のみです
- URL を扱う依存ライブラリを、安全性の問題が修正された版に更新しました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

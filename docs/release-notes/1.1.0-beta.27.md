# Xirius 1.1.0-beta.27

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 外部のプラグインの窓の上の帯で、プリセットの一覧・前後の切り替え・経路の印が効かなかったのを直しました。プラグインの準備中に押した操作も、準備が終わると効きます
- 帯のピンを押してから効くまでが遅かったのを直しました
- 帯の電源を押すと、プラグインが落ちる・入れ直せないことがあったのを直しました。電源を切っている間は、エフェクトは元の音をそのまま通し、楽器は鳴りません

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

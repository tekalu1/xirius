# Xirius 1.1.0-beta.6

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 設定の画面とインサートの一覧から、プラグインの再スキャンができなかったのを直しました
- プラグインを差した直後に、編集の窓が開かなかったのを直しました。読み込みが終わってから開きます
- プラグインのスキャン中に曲を作ったり開いたりしても、スキャンが失敗にならないようにしました
- 再スキャンが始まるとき、押したままの鍵盤の音が鳴り続けないようにしました
- プラグインの窓を開けなかったときは、そのことを知らせるようにしました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

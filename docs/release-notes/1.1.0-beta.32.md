# Xirius 1.1.0-beta.32

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 外部 VST3 プラグインのプリセット一覧を、そのプラグインの窓の手前に、帯のすぐ下から開くように変えました。検索欄に名前の一部を入力して絞り込めます。上下の矢印キーで項目を移動し、Enter で選べます
- Esc を押すと、検索欄に文字があれば消去し、空なら一覧を閉じます。同じボタンをもう一度押すか、一覧の外やプラグインの中をクリックしても閉じます
- 「名前を付けて保存…」の入力フォームと「ファイルから読み込む…」のファイル選択画面は、操作したプラグインの窓の上に出るように変えました
- メイン、チャンネル、内蔵の楽器の窓を押したとき、表示中の外部プラグインの窓を本体より上に並べ直すように変えました。外部の窓が複数あるときは、最後に操作した外部の窓を一番上に置きます
- Shift+F11 で外部プラグインの窓を開くと、開く操作をした本体の窓が前面に残っていれば、新しく開いた窓にキー入力先を移すように変えました
- 外部 VST3 楽器の窓を開き直す自動試験で、ホストから開いた通知が届き、新しい窓を確認してから画像を取得するように変えました

これらの変更は Windows の外部 VST3 プラグインが対象です。macOS には外部プラグインの窓がまだありません。

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

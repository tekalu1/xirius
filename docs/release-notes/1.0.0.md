# Xirius 1.0.0

最初の公開版です。Windows 10・11（x64）向けです。

- オーディオと MIDI を録音し、アレンジとピアノロールで編集できます（コンピング・オートメーション・トランスポーズ）
- トラックとフォルダー、インサート・センド・内蔵のエフェクトで、ミキサーで混ぜられます
- VST3 と CLAP のインストゥルメントとエフェクトを使えます（必要なら別のプロセスで動かせます）
- DAWproject の読み込みと書き出し、WAV・FLAC・MP3 の書き出しができます
- Fender Studio Pro のキーの割り当てを取り込めます
- コマンドライン（xirius）と MCP のサーバーから、曲を操作できます
- 新しい版が出ると「Xirius について」で知らせ、「更新して再起動」で署名を確かめてから入れ替えます

Xirius は Fender・PreSonus とは関係がありません。インストールの手順と、署名の無いプログラムへの
Windows の警告の扱いは、README の「Installing on Windows」にあります。

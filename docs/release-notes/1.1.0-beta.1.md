# Xirius 1.1.0-beta.1

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- アレンジとミキサーでトラックの選択が連動し、Ctrl で選択の追加・解除、Shift で範囲選択ができます。選んだトラックの音量とパンは、差を保ったまままとめて動かせます
- ブラウザーの試聴を改善しました。読み込み中も操作でき、前後のファイルを先読みします。一度試聴したファイルも速く再生でき、読み込み中の表示と波形で進み具合が分かります
- 別の曲を開くとき、前の曲の録音ファイルの整理で画面が待たされにくくなりました
- アレンジとピアノロールのグリッドを見やすくしました。小節・拍・細かい区切りを見分けやすくし、拡大率や拍子に合わせて目盛りを表示します
- 機器や入出力などを選ぶ一覧で検索できるようになりました。日本語入力と貼り付けにも対応し、設定の内側の余白を押すと閉じてしまう問題も直しました
- 機器のプリセットを .xpreset ファイルで保存・読み込み・名前の変更ができます。内蔵機器のタイトルバーをそろえ、Sampler と Drum Kit で WAV・AIFF・FLAC のサンプルを使えるようになりました
- 内蔵 Compressor が外部サイドチェーンに対応しました。検出音のゲインとフィルターを調整し、Listen で検出音を確認できます
- クリップのトランスポーズを変えたときの反応を改善しました。ピアノロールなどの下部パネルの切り替えも、アイコンと選択状態で見分けやすくしました

コマンドラインでは、複数トラックの音量やパンを相対的に変更できます。プリセットの管理やサイドチェーンの設定に加え、スプリッターでエフェクトを並列につなぎ、分岐ごとの音量・パン・ミュートを調整できます。

スプリッターの分岐内にある機器へのサイドチェーンと、マスターの分岐内のオートメーションのタイミング補正は未対応です。試聴の待機アニメーションと読み上げ、環境によってクリップのトランスポーズがホイールで変わらない症状は、確認を続けています。

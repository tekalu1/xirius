# Xirius 1.1.0-beta.37

This beta is for Windows 10 and 11 (x64). To receive beta updates in the app, turn on **Receive beta versions** in Settings.

## Fixed

- Fixed ARA clips that could stay at 0% after reopening a song until you clicked the clip.
- Fixed the stacking order of ARA editors when returning to Xirius from the taskbar, clicking the main window, and opening or closing the Channel Editor.
- Editing or removing ARA now marks the song as unsaved and prompts you to save when closing the song.
- The confirmation when closing a song or quitting stays visible above external plugin windows.
- If you open an ARA song before plugin scanning finishes, **Retry** now uses the updated plugin list.

## Known issues

- Xirius may continue using CPU while the confirmation for closing a song or quitting is open. This is under investigation.

If the in-app update from 1.1.0-beta.2 or 1.1.0-beta.3 fails, close Xirius and use the installer on this page.

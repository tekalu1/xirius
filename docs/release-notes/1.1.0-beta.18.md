# Xirius 1.1.0-beta.18

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 「最近の曲」の行を、1 回のクリックで開けるようになりました
- 一部のプラグインを載せた曲で、閉じるときや「更新して再起動」のときに「保存しています」が何度も出るのを直しました
- 読み込みの遅いプラグインがあると、曲を開いたときにトラックが「準備できませんでした」になることがあるのを直しました
- Drum Kit の窓で、パッドごとのつまみ（Env・Filter・Pitch・Amp）が窓の外に切れて見えないことがあるのを直しました。音の無いパッドを選んでいる間は、つまみを薄く表示します
- Drum Kit のパッドを、Ctrl・Shift で複数選んで、つまみをまとめて回せるようになりました
- Drum Kit のパッドのオートメーションが、「A1 Kick · ボリューム」のような名前と、dB などの単位で表示されるようになりました。鳴っている途中の音量・パン・ピッチの変化も、なめらかになりました
- Drum Kit の Choke の一覧が開かなかったのを直しました
- フォルダーを作ると、同じ名前のバスが一緒にできて、つながるようになりました。フォルダーの名前を変えるとバスの名前も変わり、フォルダーを消すとバスも消えます

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

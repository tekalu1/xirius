# Xirius 1.1.0-beta.38

This beta is for Windows 10 and 11 (x64). To receive beta updates in the app, turn on **Receive beta versions** in Settings.

## New

- When a track is soloed, the M of each track that goes silent because of it now turns yellow and the track name fades, in both the track headers and the mixer. A mute you turned on yourself still looks the same as before.
- New M and S buttons at the bottom of the track headers turn every mute or solo off at once. Press the same button again to put them back.
- The selected track's lane is now a calmer shade, and the selected clip's name is shown in bold, so the selected clip stands out from its lane.

## Changed

- In the piano roll, dragging outside the clip with the arrow tool now only selects notes. To draw a new part, use the pencil.
- AI assistants connected through MCP can now read the song (track and clip lists, status) while you are working, for example with a plugin window open or during a drag. Changes from the assistant still wait until you are done.

## Fixed

- Where clips overlap, clicking, dragging or resizing now picks the clip shown on top instead of the one hidden underneath.

## Known issues

- Xirius may continue using CPU while the confirmation for closing a song or quitting is open. This is under investigation.

If the in-app update from 1.1.0-beta.2 or 1.1.0-beta.3 fails, close Xirius and use the installer on this page.

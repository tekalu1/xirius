# Xirius 1.1.0-beta.11

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 右クリックのメニューを整理しました。よく使う操作だけを上に置き、ほかは分類ごとにまとめて横に開くようにしました。メニューの上の検索から、すべての項目を探せます
- 左のインストゥルメントとエフェクトの一覧を、プリセットと合わせて 1 つの「トラックブラウザー」にまとめました。機器を開くと、その機器のプリセットが並びます
- インストゥルメントのプリセットを、後ろの FX ごと保存できるようにしました。FX を含めたプリセットには「+FX」の印が付きます
- 機器とプリセットに、お気に入りの印を付けられるようにしました
- ドラムキットと Sampler の「Browse」で、ファイルを選ぶ窓を開くようにしました。複数のファイルを選ぶと、空いているパッドへ順に入ります
- 知らせを、再生ボタンの並ぶ帯のすぐ上に出すようにしました。下の欄の高さでは動きません
- 曲のプールの「使われていない録音を整理…」が、メニューを開き直すまで選べなかったのを直しました
- 音声の設定で入力のチャンネルを選ぶと、画面が正しく描かれないことがあったのを直しました
- プラグインの画面で遅延の変わる設定を動かしたとき、遅延の補正が古いままになることがあったのを直しました
- ARA のプラグインを使う曲で、解析の結果を取り込むときに画面が待たされることがあったのを直しました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

# Xirius 1.1.0-beta.8

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- スプリッターの分岐を、本数の上限なしで足せるようにしました。分岐の並びの右とストリップの Splitter の行に ＋ を置きました
- 分岐の ✖ を押すと、いつでもその分岐を削除します。2 本のときはスプリッターを外して、残る分岐のエフェクトを縦に並べます。どちらも元に戻せます
- ミュートした分岐は、線が途切れて黄色の M が付くようにしました
- 分岐の音量とパンを、数で入力できるようにしました。ダブルクリックか Enter で入力できます。パンはチャンネルエディターと広いストリップに出します
- トラックの頭の列を広げると、名前が広がった幅を使うようにしました。ボタンとメーターは右の端に並びます
- トラックの頭の列に余裕があるときは、音量のフェーダーを出すようにしました
- マクロやホイールで動かした後の「元に戻す」が、1 回で戻らないことがあったのを直しました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

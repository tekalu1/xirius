# Xirius 1.1.0-beta.23

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- ミキサーの機器の並びで、行と行の境目にポインターを置くと、線と ＋ が出るようになりました。線を押すと、その場所に機器を挿せます。いちばん上の境目から、最初の機器の前にも挿せます
- 機器を並べ替えるときと、ブラウザーから機器をドラッグするときに、挿す場所の線が出るようになりました
- トラックの色の四角を無くし、トラックのアイコンに色が付くようになりました。アイコンを押すと、色を選べます。ミキサーのチャンネルのアイコンからも選べます
- 機器の行の入・切の印が、機器の窓と同じ電源のアイコンになりました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

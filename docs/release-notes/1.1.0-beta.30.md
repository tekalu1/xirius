# Xirius 1.1.0-beta.30

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- アイコンボタンは、選ばれていないときの面をなくし、選んだ道具の面を青に変えました
- ボタン・文字入力・つまみ・クリップやノートの端など、操作する場所とドラッグの方向に合わせてカーソルが変わるようにしました
- スタート画面に「設定」を加え、曲を開く前に一般設定を開けるように変えました
- アレンジとピアノロールのルーラーを 2 段に変えました。上段はループ、下段は時刻と再生位置です。下段の横ドラッグで再生位置を動かし、縦ドラッグで拡大・縮小します
- MCP の接続先とトークンを保存し、起動し直しても同じ情報で接続できるように変えました。保存したポートが使用中のときは、その回だけ別のポートを使い、AI の画面で知らせます。保存した接続情報は変わりません
- AI の画面に「作り直す」を加えました。確認して実行すると接続先とトークンを両方変えます。登録済みの AI のアプリには、新しい情報を登録し直してください
- 移行の注意: この版に上げた最初の起動で接続先とトークンが新しくなります。AI のアプリへ一度登録し直してください
- プラグインの準備待ちや録音開始のタイミングによって時々落ちていた試験の待ち方と計測方法を変えました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

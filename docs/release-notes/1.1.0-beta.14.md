# Xirius 1.1.0-beta.14

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 起動したときの画面で「最近の曲」の最初の行を開こうとすると、その曲が開かずに「新しい曲（保存前）」が増えていたのを直しました
- 何も入れないまま離れた新しい曲は、「最近の曲」に残らないようにしました
- 起動したときの画面で、右クリックやキーの操作が、後ろに隠れた曲に届いていたのを直しました
- 検索欄と名前の欄で、カーソルの移動・範囲の選択・コピーと貼り付け・元に戻すが使えるようになりました。マウスでも選べます。名前の変更は、名前を全部選んだ状態で始まります
- 検索欄の形をそろえました。文字があるときは右端の ✖ で消せます。Esc は、文字があれば消し、空なら閉じます。一致した部分は太字で示します
- 検索欄から ↓ で一覧に移り、キーだけで選べるようになりました。Ctrl+F でトラックブラウザーの検索欄に入れます
- トラックブラウザーの検索欄と、バージョン名・書き出し名の欄が、日本語の変換での入力に対応しました
- トラックブラウザーのお気に入りに入れた機器を開いて、中のプリセットを選べるようになりました

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

# Xirius 1.1.0-beta.2

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 曲を開くあいだ、読み込みや音の準備の進み具合とトラック名を表示します。Esc または「中止」で取りやめられ、音の準備を中止すると開始画面に戻ります
- 音の準備で一部のトラックの読み込みに失敗したとき、理由を確認して再試行するか、失敗したトラックを「音なし」で開くかを選べます
- プラグインが応答せず状態を保存できないときは、未保存として扱います。曲の切り替えや終了の前にも確認します
- 設定・ブラウザー・書き出しなどで、ファイルや機器の応答を待つあいだも画面を操作できるようにしました。ブラウザーの一覧や波形の読み込み中も表示が止まりにくくなりました
- 最近の曲・新規作成・サンプル・DAWproject の取り込みなどでも、曲を開く進み具合の表示と中止の操作をそろえました。ファイルの読み込みを中止したときや、読み込みに失敗したときは、元の曲と編集履歴を保ちます
- 設定・「Xirius について」・コマンドパレットから、更新を手動で確認できます。起動時の更新確認をオフにしていても使え、更新の進み具合や失敗の理由を確認できます
- コマンドパレットの結果を日本語の項目名で表示し、長い内容は幅に合わせて折り返します。結果の全文を選択してコピーできます

スプリッターの分岐内にある機器へのサイドチェーンと、マスターの分岐内のオートメーションのタイミング補正は未対応です。試聴の待機アニメーションと読み上げ、環境によってクリップのトランスポーズがホイールで変わらない症状は、確認を続けています。

# Xirius 1.1.0-beta.5

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 内蔵 EQ のグラフの点を押して離すと、そのバンドのオン・オフが切り替わるようにしました。オフのバンドは輪で描きます
- ループの帯を押して離すと、ループのオン・オフが切り替わるようにしました。帯の上でも小節の番号が読めます
- ピアノロールのループの帯でも、右クリックのメニューが開くようにしました。項目はアレンジと同じです
- ミキサーの「インサート」の見出しを別のトラックへドラッグすると、エフェクトを同じ並び・同じ状態で写せます。Shift を押しながら落とすと後ろに足します
- 「インストゥルメント」「インサート」の見出しの ＋ を、いつも出すようにしました。右クリックからも、レイヤー・エフェクト・スプリッターを追加できます
- 狭いストリップでは、入れ子のスプリッターを閉じた形で始めます。押すと 1 段ずつ開きます
- EQ のバンドのオン・オフのオートメーションが、細かい値で書けてしまい、書いても効かなかったのを直しました。切り替えの値は段で書き、再生のとおりに効きます

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

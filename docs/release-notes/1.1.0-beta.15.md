# Xirius 1.1.0-beta.15

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- 起動したときの画面の「最近の曲」から、保存前の曲を削除できるようになりました。行を右クリックして「削除」を選ぶか、行を選んで Delete キーを押すと、確認の窓が出ます。保存した曲は対象になりません
- 「最近の曲」で、長い曲名が右の時刻に重なって読めなくなっていたのを直しました。名前は「…」で省略し、時刻と「（保存前）」の印は必ず見えます

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

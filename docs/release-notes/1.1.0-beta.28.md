# Xirius 1.1.0-beta.28

Windows 10・11（x64）向けのベータ版です。更新の通知で受け取るには、設定の「ベータ版も受け取る」をオンにしてください。

- MCP で AI に見せるツールを、コマンドごとの数百件から 7 件に減らしました。AI が最初に読む量が約 450 KB から約 6 KB になります
- 移行の注意: `note_transpose` などのコマンドごとのツール名は、MCP から呼べなくなりました。AI のクライアントでツールごとに許可していた場合は、新しい入口ごとに許可し直してください
- 入口は、見るだけの `run_read`、編集の `run_edit`、保存と書き出しの `run_guarded`、削除を伴う `run_destructive` の 4 つです。どれにも `command`（`note.transpose` など）と `args` を渡します。`run_edit` を常に許しても、保存と書き出しは通りません
- コマンドは `ops_list` で探し（各行の `tool` が使う入口）、引数は `ops_schema` に `name` か `group` を渡して調べます。まとめて 1 回で承認するときは `ai_batch` です
- 入口を取り違えると、エラーの結果に正しい入口が付きます。AI の権限の段・保存の許可・結果は前と同じです

1.1.0-beta.2・1.1.0-beta.3 からは、アプリの中の更新で新しい版が入らないことがあります。そのときは Xirius を閉じてから、このページのインストーラーで入れてください。

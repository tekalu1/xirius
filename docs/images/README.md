# Pictures for the README

`main.png` is shown near the top of `README.md`: the arrange window of 1.0 with the sample song
(「夜の散歩」, made for the app), the piano roll open below, on the dark theme, 1600 px wide.
`docs/ui-approved.md` has the approved shape of the screen.

When it is taken again, look at it for what must not be published:

- no path of this PC in a title bar, a browser tab, a tooltip or the About window;
- no song name, track name or clip name from a real session (use the sample song);
- no plugin name or brand of a plugin from this PC (use the instruments and effects that ship
  with the app, or a made-up name);
- no account name, e-mail address or avatar.

PNG, no shadow or border (the README adds no frame), and under a megabyte.
